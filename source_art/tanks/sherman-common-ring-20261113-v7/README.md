# 三型谢尔曼共用座圈（第七轮）

用户要求：M4A1、M4A1(76)、M4A3E2车身的炮塔座圈尺寸与位置相同，圈内全部使用黑色，不再使用车身色。此为本轮美术统一约束。

## 基础与方法

- 普通及76型车身沿用第五轮履带校正稿；巨无霸沿用第六轮用户新三视图重画稿。基础图归档于 `references/`。
- 三型统一800×1400画布、800像素名义车身长。座圈共用同一张236×236透明配件图，中心统一`(400,720)`，即车头基准`y=340`向后380像素。相同尺寸、相同坐标、相同朝向，没有分别拟合三张圈。
- 内置 `image_gen` 生成黑色内圈座圈配件，并分别清理三个旧座圈局部、补齐橄榄绿甲板。提示词保存于 `prompts/`；原始输出保存于 `generated/`。没有使用CLI图像生成。
- 脚本只处理局部图块融合、共享图层裁切/缩放、透明边整理及确定性合成。复用同一座圈栅格，统一放置于`left=282,top=602`。生成内圈本身RGB已为黑色；规范低透明度并将黑色内部保持为不透明`#000000`。
- 炮塔美术和比例沿用原稿，按各自源支点重新放到统一圈心`(400,720)`。不重新设计车型轮廓或顶部附件。

## 成品与审阅

- `candidates/`：三型各车身、炮塔、支点合成，共9张真实RGBA透明PNG，均800×1400。
- `common-ring-review.png`：三型车身及同尺度局部座圈并排。
- `assembly-review.png`：统一支点后的合成、76/78像素车身长及最近邻3倍预览。
- `generated/common-ring-236.png`：三型共用的规范座圈。
- `review-audit.json`：统一坐标、尺寸、黑色填充与覆盖检查。

## 检查结果

- 三型复用座圈的全部不透明像素均与共用配件一致，差异为0；圈心与配件尺寸完全相同。
- 内圈保守半径98像素内共30172点均为不透明RGB`(0,0,0)`，各型黑色检查差异为0。
- 旧圈局部和新圈工作区之外，车身图像像素逐字节保持原样，包括履带、舱盖、车首、工具与格栅。
- 以共同圈心在外缘及±2像素邻近采样，每型1800点均被朝前炮塔覆盖。
- 已检查透明、支点合成与地图尺寸；尚未进行游戏内目视验收。
