# Maus redraw — review draft

Four transparent PNGs at 200 × 79 pixels: complete tank, hull, turret, and destroyed tank. The complete tank is composited from the separate hull and turret layers on a shared canvas. Front points left.

This is a review draft only. No files in `assets/resources/textures/units`, visual configuration, or Cocos metadata were changed for this draft.

## External research used

- [The Tank Museum: A Maus Tale](https://tankmuseum.org/a-maus-tale/) — project history, 12.8 cm and 7.5 cm gun pairing, roof hatches, surviving hybrid vehicle.
- [Panzer Tracts 6-3 publisher page](https://daviddoylebooks.com/axis-military-vehicles/panzer-tracts-no6-3-pzkpfw-maus-and-e-100) — identifies the archive-based scale drawings and period photographs used to study the vehicle.
- [Panzer VIII Maus orthographic blueprint listing](https://drawingdatabase.com/panzer-viii-maus/) — top and side silhouette study.

The draft was generated as a new illustration from these external references and descriptions. No existing Maus images from this game were used as visual input. The hull and turret were isolated from the new illustration, then resampled and composited at the final pixel size. The destroyed variant derives from the same new illustration.
