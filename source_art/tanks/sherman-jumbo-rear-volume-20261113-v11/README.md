## 尺寸与保护区

- 成品画布800×1400，车身外廓416×800、车首y=340，保持第十轮用户指定宽度。
- 后部局部工作区：`left=192,top=840,width=416,height=300`。生成局部对齐后，在起始20像素及外侧3像素做过渡融合。
- 使用原车身整个alpha图，所有透明边界保持逐像素不变，没有改变车体外廓或占地。
- 工作区之外、前半车身和座圈像素不变；后履带区域（y>=1098、x<282或x>=518）保留原像素，不使用生成的新履带纹理。
- 公共黑色座圈仍236×236、中心(400,720)，不透明图案与公共配件差异0，黑色内部差异0。
- 炮塔沿用第十轮，未重画。座圈外缘附近1800个点仍全部被朝前炮塔覆盖。
