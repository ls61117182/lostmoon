# 鼠式击毁图毁伤加强

已安装到游戏灰色与 late_war 迷彩击毁资源。以当前已确认的正常车身为唯一底图，通过内置 imagegen 绘制座圈、格栅、检修盖、侧裙四处局部破损，再按固定坐标和蒙版合成。

- 座圈增加大块撕裂翻边和黑色内部断裂结构。
- 格栅增加明显的黑色破口、断裂栅条和翻折边框。
- 后部检修盖出现大面积斜向撕裂、翻起盖板和暴露舱室。
- 侧裙局部破损，露出断裂履带结构。
- 车身与击毁图仍为 258×99，透明轮廓完全一致；油桶像素不变。损伤蒙版外 17,527 像素与正常车身完全相同。
- 正常整车、车身、炮塔的灰色及迷彩文件均与本次修改前字节一致；不修改座圈、油桶或渲染坐标。

`damage-comparison.png` 展示正常车身、加强前后击毁图，各含原始尺寸和 2 倍最近邻放大，属于资源离线对比图。

验证：迷彩已同步重建；`pnpm run tank:validate` 通过 34 车型资源审计、21 项测试和 TypeScript 检查。灰色与迷彩均验证损伤区外像素一致、轮廓一致。已检查小尺寸资源预览；实际游戏观感待用户刷新预览查看。

完整生成提示词见 `PROMPTS.md`；局部输入、生成稿和可复现合成脚本 `apply_damage.py` 均保存在本目录。备份路径及像素统计见 `game-integration.json`。
