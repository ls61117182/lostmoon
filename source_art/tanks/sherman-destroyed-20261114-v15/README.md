## 击毁表现

- M4A1：炮塔左后侧撕裂破口、后部发动机盖翻折露出暗腔、右后履带损坏。
- M4A1(76)：炮塔左前破口、顶部机枪变形、后盖右后角翻折及左后履带断损。
- M4A3E2：炮塔左侧顶面破口、左侧发动机格栅破损、右后履带撕裂；保留弧形肩部和右侧完整格栅作为识别特征。

三型均保留大部分正常橄榄绿及未损区域亮度，焦黑集中在损伤周围；少量大破口、卷曲边缘、变形格栅和断履带在小尺寸下可读。炮塔保持装车及原朝向，主炮保留原长短和炮口，不统一强制断炮。破口内部为有深度的深色不透明区域，非背景透明孔。没有人物、火焰、烟雾、外部地影或大范围散落碎片。

## 工具与对齐

使用内置`image_gen`，每型以自身正常合成作为编辑目标分别调用；没有用其他车型替换结构，没有调用CLI。完整提示词为`prompts/*_destroyed.txt`，原始输出为`generated/*_destroyed-v1.png`。

按生成图两端履带/车体的横向跨度定位车首，取尾部实物末端作为车尾；以正常图的车身长为基准仅做一次整体等比缩放，按车身中轴和车首对齐。没有将炮塔、主炮和车身分别缩放，没有因为画布留白差异将车身重新铺满或变大。`build-review.cjs`只做量取、等比缩放、透明边清理、基准对齐和审阅排版，不绘制损伤。

对齐后的量取误差：普通型车首0/车尾-1像素；76型车首-1/车尾-1像素；巨无霸两端均0。整体实物外廓宽度分别370、369、415像素，与正常稿367、367、416相比差异均不足1%；包含损伤形变、生成轮廓及重采样边缘差异。没有把这种差异宣称为精确相同外廓；尺寸与位置记录公开于审计文件。
