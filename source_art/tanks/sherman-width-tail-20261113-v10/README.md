# 用户指定宽度调整与76型尾部履带修正（第十轮）

本轮按用户明确指令修改：巨无霸宽度取修改前M4A1(76)的宽度；M4A1(76)宽度改成与普通M4A1相同。用户文字写作“M4A2(76)”，但随附截图标题与既有资源均为M4A1(76)W HVSS，因此尾部修正针对截图中的M4A1(76)。

用户此前已明确允许PNG像素级裁切与对齐。本轮为精确尺寸调整与履带像素复用，没有调用图像生成工具、没有引入其他车型参考或重画炮塔。宽度要求覆盖此前按单张参考长宽比保持的设置。

普通M4A1车身保持原图像素不变。76型从第七轮已由图像工具清理旧圈的甲板重建无圈车身后收窄；巨无霸使用第八轮原图独立重画的无圈源图加宽。炮塔图像及支点均沿用最新候选。

## 尾部修正

截图指出的圆角装甲下方存在透明缝隙，导致后履带像悬空。只复用本身后履带像素向上延伸到装甲下方，保留现有装甲作为遮挡层。

- 左履带横向范围`[228,287)`，右履带`[514,573)`，两侧外露宽度59像素，不向装甲外侧增加宽度。
- 工作区y为`[1025,1080)`。复用原后履带行的镜像延伸，未绘制新纹理。
- 仅补透明和低透明度边缘，alpha>=240的原装甲/履带像素保持原样。
- 两个履带工作区之外改变像素数0；补齐545个像素，内部透明缺口从361个降至0。
