## 核心验收要求

本轮重点：车首左右履带前端均位于外侧，与铸造车体鼻部、角形前挡泥板保持用户图中的相对位置、前后起点和遮挡关系；不能把两侧履带整体画没、内移到车首下面、推到驾驶舱后，或用两块实心绿色矩形替代外露履带。可见的履带外缘/后端也须按图保留。普通型与76型的履带宽度、挡泥板、车首小/大舱口不能混用。

炮塔按图保留舱口数量、通风/瞄准部件、炮盾、炮管比例及图中顶置附件；75型顶置附件在炮塔右侧，76型在左侧。76型本轮必须有图示制退器。车体后部为M4A1发动机甲板盖，不套用M4A3双格栅。炮塔/车身分层不得串入对方的零件。

使用内置 image_gen，完整提示词位于 `prompts/`，生成原稿位于 `generated/`。所有车体美术由图像工具重绘；脚本仅用于参考裁切、等比缩放、支点合成和审阅排版。PNG保持真实透明。本轮参考和候选属于项目美术，不属于翻译文件归档。
