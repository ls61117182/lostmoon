# Panzer III Ausf. N art

`reference.png` is the user-provided three-view. `reference-turret-aligned.png`, `reference-turret-top-4x.png` and the gun crops show its unmarked overhead artwork. The two red annotation images are rough location guides only; their strokes were not used as an alpha mask. `turret-isolated-from-original.png` records the turret identified from the original image's real seams and silhouette. The grey `*-turret-generated.png` images follow that shape and the original short gun's narrow muzzle, rounded middle sleeve and broad breech jacket. The darker `*-turret-color-matched.png` variants were compared to the M turret at game size; `gradePanzer3N.cjs` lifts their midtones to the M turret's sampled grey while leaving the geometry and alpha intact, producing `*-turret-matched-midgrey.png` for the production sprites. No M turret pixels were used. The plain N turret has no external rail; the Schurzen version adds the thin surrounding rail and supports.

Run `node tools/gradePanzer3N.cjs` and then `node tools/preparePanzer3NSource.cjs` to fit both graded turrets to the approved M hull using the actual turret-to-hull proportions of the overhead drawing, creating the `*-turret-selected.png` source images. The source manifests in `data/tank_art/` use those turrets with the corresponding M hull and wreck source. Run `node tools/prepareTankArt.cjs --kind panzer3_n` and `node tools/prepareTankArt.cjs --kind panzer3_n_schurzen` to rebuild production textures and geometry.

Run `node tools/previewPanzer3N.cjs` to refresh `preview-comparison-3x.png`, which shows both M and N versions at three times their game texture size.
