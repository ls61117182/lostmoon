# 第四轮：车身炮塔座圈与76型炮塔修正

用户本轮明确要求：两型车身须绘制炮塔座圈；M4A1(76)炮塔以上一轮较早的76型炮塔为基础修正。候选仍不接入或替换游戏资源。

## 输入与范围

- 车身使用第三轮两型已修正履带前端的原稿，在原图上只补座圈，保留履带、挡泥板、驾驶舱与发动机甲板。
- 76型炮塔修改基础：`sherman-redraw-20261113-v2/generated/m4a1_76_turret-v2.png`。用户允许参考此上一版候选，覆盖此前本轮不使用旧候选的通用约束；没有把游戏内原资源作为基础。
- 用户此前给定的第二张图继续约束76型HVSS方案、制退器和顶置附件位置；不能退回VVSS/无制退器的旧次级配置。
- 普通M4A1炮塔沿用第三轮，无需重画。巨无霸、击毁状态和车长资源不在本轮修改范围。

## 座圈与分层

座圈画在车身真实旋转支点上，保持正俯视圆形、低矮金属圈、双同心结构边和暗色内凹部。不是新增炮塔或高圆筒。座圈必须小于炮塔外形，完成分层后按同一支点确定性合成，核对遮挡和小尺寸。

使用内置 image_gen 进行三张局部编辑，完整提示词在 `prompts/`，输入副本在 `references/`，原稿在 `generated/`。`m4a1_turret-unchanged.png` 是本轮明确沿用的普通炮塔。脚本仅做等比缩放、支点叠加与排图，不绘制美术部件。

## 交付与验收

- `changes-preview.png`：两型带座圈车身、普通炮塔与修正后的76型炮塔。
- `assembly-review.png`：同一支点合成，76px车身长原尺寸与最近邻3倍预览。
- `candidates/`：四张 `*_hull.png` / `*_turret.png`，同为800×1400真实透明画布，按画布原点直接叠加；另有确定性合成 `*_assembled.png`。
- `ring-measurements.json`：根据实际生成图座圈的径向亮度边缘拟合圆心。普通型源图圆心(424,868)，76型(390,1125)。这不是直接照抄生成提示词里的近似坐标。
- `review-audit.json`：等比缩放、共同支点、透明像素与座圈周缘遮挡结果。车身保持原车首及车长位置，将炮塔旋转点落到实际圈心。

已检查两个座圈的圆形、前后位置、车首两侧履带保留、76型炮塔较宽轮廓/后部与附件、分层独立性、合成遮挡与小尺寸。正常朝前合成中，两个座圈外缘附近各采样1800点，全部被炮塔的不透明轮廓覆盖，未露圈。该检查是二维预览检查，不代表已完成游戏内目视验收或正式坐标配置。

76型以用户指明的旧候选为修改基础，保留其外形、前盾及两个舱口，并加上当前HVSS参考要求的制退器和左侧顶置附件。保留此前候选供对照，本轮未修改游戏 `assets/`、CSV、meta或注册，也未绘制其他资源。

复现量取与排图：先运行 `node source_art/tanks/sherman-rings-turret-20261113-v4/measure-rings.cjs`，再运行同目录的 `build-review.cjs`。不对车辆做非等比拉伸；只清理alpha≤4近透明边缘杂点。
