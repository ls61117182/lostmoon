## 先做结构判断

`structure-analysis.png`在本轮美术生成之前制作：从用户侧视、前后视和俯视关系区分斜首板、乘员舱顶、后部发动机甲板与尾板。它是面向关系示意，不是带实车尺寸的工程图，也没有作为生成工具的额外车型参考。

本轮采用的解释：基本焊接壳体左右对称，前后方向存在高度和坡面变化；正俯视不能将直立侧板画成宽大的侧向斜面。后部顶面与尾板的面向区别，通过横向边缘、厚度、格栅嵌入与接触阴影表现，不添加无依据的纵向对角折线、多边形高台或一侧宽一侧窄的面。

这一结构约束与附件布局分开：机枪、小圆盖、舱盖及工具按用户原图保留真实不对称，不整体镜像。
