## 历史参考

- 俯视几何：[《Фердинанд》图册](https://porschecarshistory.com/wp-content/old/biblio/75/2.pdf)，PDF第26页（零起始25）Elefant 1:35俯视线图。原PDF保存为 reference-book.pdf，页面及裁切保存为 reference-top-plan.png / reference-top-crop.png。
- 结构与涂装：[田宫35325象式说明书](https://www.truckmo.com/media/pdf/90/4b/db/Tamiya_Dt-_Jagdpanzer_Elefant_300035325_Modellbauanleitung_TRUCKMO_WINGSMO.pdf)，第3页核对战斗室顶盖、车长观察塔和前部三格栅发动机舱；1944年意大利战场色彩方案。保存为 reference-tamiya.pdf。
- 尺寸及车组：[Elefant资料汇总](https://en.wikipedia.org/wiki/Elefant)：含炮全长8.14米、宽3.38米、88毫米PaK43/2 L71、六人车组及双装填手。

历史结构优先保留：后置固定战斗室、前部发动机舱三块格栅、长炮管及制退器、观察塔、非对称舱盖与通风器布局。小尺寸图简化了铆钉、防磁涂层纹理、工具和格栅条数量。迷彩为历史风格重绘，不声称复刻某一辆具体编号车辆。

正常：三份输入分别是Elefant正俯视几何、1944改装结构、SU-152画风。严格正俯视，炮口朝左；按参考保持后置战斗室、三格栅前部发动机舱、观察塔和非对称舱盖位置。暗黄绿褐迷彩，深色粗轮廓，清晰少量色块，削减细小铆钉、噪点与纹理，透明背景，不含文字、阴影或地面，供200×84左右尺寸使用。
