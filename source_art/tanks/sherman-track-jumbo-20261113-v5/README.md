# 第五轮：履带等宽/覆盖关系与巨无霸座圈、统一配色

本轮合并保留用户前一条尚未完成的巨无霸任务，以及新给的履带修正要求。所有产物仅候选，未替换游戏资源。

## 范围与依据

- M4A1(76)W HVSS：修正左右各条履带前后外露段的横向宽度及内外边界，前后应等宽并位于同一条直线投影；履带位于上方侧装甲之下，不能从车体侧缘凸出。
- 用户红框截图实际展示普通M4A1的同类问题，因此普通M4A1同时做同样的宽度/覆盖校正。截图仅问题说明，不作为要复制的红框或背景。
- 两型车身、炮塔座圈及已有车首布局不重新设计；不通过加宽车体/装甲掩盖履带错误。普通与76型炮塔沿用第四轮。
- M4A3E2：在第二轮车身补座圈；车身和炮塔的画风、配色统一到另两型的温暖橄榄绿、深色轮廓和清晰平滑明暗。保持巨无霸自身焊接车体、双格栅、专用炮塔和厚炮盾几何，不套用M4A1的车体/甲板。

## 工具与文件

巨无霸车身座圈与车身、炮塔风格调整使用内置 image_gen；完整提示词在 `prompts/`，输入/风格参考在 `references/`，原始生成在 `generated/`。履带图像编辑初次尝试未达到严格等宽要求，后续用户明确选择“允许像素级裁切与对齐（推荐）”，因此最终两型履带由 `align-tracks.cjs` 复用原图履带像素做精确裁切与对齐。没有使用 CLI 图像生成。未改动的两个炮塔也复制在新目录中，便于独立复现本轮候选。

履带验收须以四个实际深色外露端的内外边界为依据，逐侧比较前后宽度和横向位置，不能只看全车缩略图。座圈按实际生成后的圈心校准炮塔，核对合成覆盖。最后展示三型同场配色与小尺寸，等待用户确认。

## 最终候选与检查

- `candidates/`：三型各一张车身、一张炮塔和一张支点合成，共9张透明 PNG。分层统一为800×1400画布，车身名义长度800像素；仅等比缩放，不分别拉伸填满画布。
- `family-review.png`：三型车身（含座圈）和炮塔并排。
- `track-alignment-preview.png`：普通及76型，逐侧并排展示车首和车尾履带；青色线只在审阅图中标记边界。
- `assembly-review.png`：支点合成、76/78像素车身长和最近邻3倍预览。仅静态尺寸检查，尚未进行游戏内目视验收。
- `review-audit.json`：源图边界、缩放、支点和座圈覆盖。每型座圈周边5圈、每圈360点，共1800点，当前朝前合成均由炮塔完全覆盖。
- `track-alignment-audit.json`：M4A1源图履带为125像素宽，左右边界分别为`[40,165)`与`[685,810)`；M4A1(76)源图履带为120像素宽，边界为`[40,160)`与`[632,752)`。同侧前后内外边界一致。两型原图分辨率不同，这两个数字不能直接用于比较实车履带宽度。

履带编辑限定在四个外露端窗口；窗外所有源像素逐字节保持一致。保持原有装甲为遮挡层，不通过加宽车身掩盖履带。清理端部黑色碎边后再导出。普通与76型沿用第四轮的车身缩放、车首位置和炮塔图；座圈中心保持不变。巨无霸补圈后按实际圈心重新对齐自身炮塔。

最终源文件（均在 `generated/`）为 `m4a1_hull-pixel-aligned.png`、`m4a1_76_hvss_hull-pixel-aligned.png`、`m4a1_turret-unchanged.png`、`m4a1_76_hvss_turret-unchanged.png`、`m4a3e2_hull-v1.png`及`m4a3e2_turret-v1.png`。`generated/m4a1_hull-v1.png`是未采用的图像工具履带尝试，不属于最终候选。确切标定值见 `build-review.cjs` 的 `V` 列表。

所有产物仅保存在本目录。未修改 `assets/`、CSV、Cocos元数据或注册表，未制作击毁等其他状态；等待用户确认后再继续。
