## 依据与形状

- 外侧车体轮廓保持左右对称，不是整车外廓向后收窄。
- 向后收窄的是顶部中央甲板；两侧为成对侧斜面。从炮塔座附近沿外侧起步，向内收至发动机甲板前方，再沿两侧平行伸向车尾。
- 实际不对称工具可以遮挡折线，不应因此改变底层对称结构。
- `references/user-annotated-folds.png`保存原标注；`user-folds-front-up.png`仅裁切、转向与放大。
- `hull-fold-guide.png`把标注近似配准到已定416×800车身。局部左线`(12,320)→(80,515)→(80,760)`；右线`(404,320)→(336,515)→(336,760)`，以x=208成对对应。这是解释用户“大概线条”的辅助位置，不宣称是精确工程尺寸。

使用内置 `image_gen`，第一张为编辑目标，第二张为配准辅助线，第三张为用户标注参考。初次请求未成功，成功重试提示词保存在 `prompts/user-annotated-folds-retry.txt`。未使用CLI。
