# 二战野战器材风格骰子

本版取代上一版浅色桌游骰，已接入玩家骰盘、敌方骰盘、结算弹窗和掷骰动画。

- 攻击：深橄榄绿烤漆 `#505835`
- 移动：蓝灰钢色 `#415255`
- 杂项：旧黄铜色 `#776135`
- 通用：暗军绿 `#4d523e`
- 点数：旧象牙色 `#ebe3c4`，深色嵌孔与磨损金属孔沿
- 已用：深炭灰绿，降低点数亮度
- 选中：黄铜金边

骰面增加切角凹框、少量边缘掉漆和黄铜刻度。装饰与骰面绑定，在旋转时一起运动，不使用随机噪点。不改变点数、概率或动作规则。

运行 `node tools/previewDice.cjs` 生成本目录的 `preview.svg` 和 `preview.png`。预览直接调用实际绘制方法，SVG 适配器替代 Cocos Graphics；上排为放大展示，下排为 58px 原始尺寸及滚动状态。这不是游戏截图。

验证：确认本版已接入游戏运行代码；全项目类型检查和 47 项骰子、动作菜单、布局与动画相关测试均通过。已检查绘制代码生成的预览。此前 Windows 游戏预览窗口截图两次超时，尚未完成实机截图检查。刷新或重新启动 Cocos 预览即可加载当前样式。
