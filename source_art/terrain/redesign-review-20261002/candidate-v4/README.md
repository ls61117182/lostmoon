# 非城市地形 V4

使用内置 imagegen 生成，完整提示词见 prompts.json，原始生成图保存在 sources/。

地表更新为更精细的草地、泥地、沙地、水面、深海、雪地、冰水与木材纹理。四款夏季树冠、四款积雪枝干、四款棕榈稳定随机摆放；森林九棵、树篱每边五棵。岩石高地为整格连体陡峭岩体，跑道宽度为普通道路约四倍。

已接入游戏。城市地面、道路和建筑完全保留旧版。安装前地形资源保存在 ../../backups/pre-v4-20261002/terrain/。

地表连续渲染仍使用 TerrainGroundRaster 与 TerrainGroundRenderer，冬季冻土、雪肩和冰岸逻辑保留。类型检查及接缝、冬季配色、机场宽度、缓存测试通过。预览是离线渲染，最终效果请运行 Cocos 游戏查看。
