## 素材结构

内置 image_gen 生成 10 张地面 / 路面 / 木板材质和 7 张透明物件源图。原始图保存在 `sources/`，生成提示词保存在 `prompts.json`，选用的雪地颜色细化记录在 `refinement-prompts.json`。导出时收紧建筑透明外沿的裁切范围，保留原图透明度。

`exports/` 中包含：

- `materials/`：10 张 384×384 的素材取样图。
- `objects/`：7 张保持透明度的独立树冠、岩石和建筑图。雪覆树冠在预览中按世界坐标叠加雪层。
- `tiles/`：24 张 222×256 的单格候选样张；格框不烘焙进图片。
- `roads/`：13 种旋转等价连接 × 夏季 / 冬季 / 城市，39 张透明道路图。
- `bridges/`：三条轴向 × 夏季 / 冬季，6 张透明桥面图。
- `transition-masks/`：六个邻边的 64 种连接遮罩，用于检查连接拓扑。

`manifest.json` 列出地形与文件、方向约定和预览地图；`validation.json` 记录尺寸、透明角、同底材接缝和道路出口检查结果。

## 衔接规则

1. 地面在整张地图的世界坐标上取样。镜像周期取样避免生成材质自身边缘色差造成额外接缝；同类地形不会因格子边界重新开始采样。
2. 草地、森林、公路外围和树篱共用草地底材，树冠和道路独立叠加。
3. 不同底材先合并为连续区域，再平滑区域遮罩并用共享世界坐标扰动边界，避免单纯沿六边形轮廓渐变仍产生硬折角。权重归一化，多地形交汇处不能逐边重复叠加透明度。
4. 河岸只在水陆交界出现，浅水与深水之间只混合水色；海滩与浅水形成连续岸线。
5. 道路和桥梁沿 E、SE、SW、W、NW、NE 方向的共享边中点连接。道路嘴与桥梁接口具有固定宽度。格线独立绘制。
6. 雪层覆盖由连续的世界坐标场控制，避免每格各有一圈雪或截然不同的覆盖。

单格样张用于确认分类、构图与画风，不应直接反复贴满地图：要获得预览中的衔接，仍须把这套坐标取样和邻格规则接入游戏渲染器。静态遮罩是拓扑参考，也不能在多地形交角处直接堆叠替代完整权重计算。运行时接入将在最终美术确认后实施。
