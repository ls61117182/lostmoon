# 城市道路资源

这套临时美术资源由两层组成，尺寸均为 **222×256 RGBA PNG**，尖顶六边形、中心锚点。

**当前采用直接硬拼方案**：城市道路与普通道路在格边直接衔接，不使用渐变底座、渐变材质或宽度过渡。保留城市道路加宽约 33% 和圆角弯道的设计。已放弃的过渡试验资源及生成脚本移入 `asset_backups/urban-road-transitions-abandoned-*`，不再放在运行时资源目录中。

- 底座：`assets/resources/textures/terrain/urban/roads/urban_road_tile_base_v1.png`，浅灰石砖铺装。
- 路面：同目录 `urban_road_surface_{rd}_v1.png`，深灰旧沥青、暗色排水边和窄石质路缘，路面之外透明。每格选择一张完整路面覆盖到底座上。
- 索引：同目录 `urban_road_manifest.json`，包含全部 64 种方向状态；`000000` 仅绘制底座，其余 63 种各有独立路面。

## 方向和拼接

文件名的六位字符串直接对应现有 `Tile.roads` / 关卡 `rd`，从左到右是 **E、SE、SW、W、NW、NE**，不是通常的二进制整数表示。

| 示例 | 含义 |
| --- | --- |
| `100100` | 东西直路 |
| `010010` | 东南—西北直路 |
| `001001` | 西南—东北直路 |
| `110000` | 两个出口夹角 60°；车辆经过时转向 120° |
| `101000` | 两个出口夹角 120°；车辆经过时转向 60° |
| `100000` | 东侧出口＋格心回车尽头 |
| `101010` | 三向 Y 型路口 |
| `110100` | 东西直路＋东南支路 |
| `111111` | 六向路口 |

全部方向已分别导出，无需旋转 PNG。六边形外接半径 128，城市路面半宽为 `128×0.24=30.72`，总宽 **61.44 像素**，比原来的 46.08 像素加宽约 **33%**；额外路缘宽 3.2。单出口回车圆半径为 `30.72×1.6`。相邻格 `d` 出口应与邻格 `(d+3)%6` 出口同时开启。接口方向仍沿用现有六向规则，城市路面宽度独立于原有乡间道路。

双出口弯道使用中心线半径 **48 像素**的等宽圆弧，两端与直线相切，内外侧路缘连续过渡；多岔路口对相邻分支的凹角做平滑合并。靠近格边的出口保持统一直线和宽度。全部 378 个方向开闭状态、192 个开放出口的宽度剖面均逐一验证。

底座和路面必须使用相同节点尺寸和位置。保留透明边距，不要紧裁路面。随资源附带的 Cocos 图片 `.meta` 将裁剪设为 `none`，中心锚点设为 `(0.5,0.5)`。只叠一张匹配 `rd` 的路面，避免把多个带路缘的分支图片互相压盖。

材质沿六边形网格的两个平移方向周期采样，使邻格出口处的沥青纹理衔接；每个路口先合并道路区域，再生成外侧路缘，没有穿过交叉口的内部描边。

## 预览、生成与检查

- `urban_roads_examples_preview.png`：底座、三轴直路、两类弯道、尽头、三至六向路口。
- `urban_roads_all_connections_preview.png`：全部 64 种方向状态。
- `urban_roads_neighbourhood_preview.png`：19 格实际拼接与现有建筑搭配。
- `road_materials_manifest.json`：内置 imagegen 的两份完整材质提示词。
- `urban_road_pavers_material_v1.png`、`urban_road_asphalt_material_v1.png`：项目内原始材质图。
- `urban_roads_validation.json`：导出图片检查结果。

在项目根目录运行 `node tools/prepareUrbanRoadArt.cjs` 可重建资源、索引及预览。现阶段只提供资源包，没有修改战场运行时的道路渲染或关卡数据。
