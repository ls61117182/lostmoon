## 美术方向

- 正俯视单线铁路；深褐色木枕、暗钢色钢轨和窄银灰亮边，灰褐碎石道床向原地表柔和过渡。
- 铁路作为覆盖层，在田野、道路、泥地上保持统一轨距和材质，两侧继续显露基底地形。
- 与道路相交采用木板平交道口；正式素材应保证两根钢轨穿过道口连续可见，木板位于轨间及轨外。
- 弯轨使用平滑曲线；分支示意采用铁路道岔，尽头示意采用木质止冲挡。
- 图中的道岔与尽头用于美术探索，不代表已确定游戏规则。
