# 城市地形重绘（2026-10-05）

使用内置 `image_gen` 生成美术，匹配当前树木与地表的自然纹理、低饱和配色和柔和明暗。

- 11 种不可破坏建筑，新增教堂、钟楼市政厅和圆顶公共建筑；4 种可破坏建筑，每种包含完整、受损、废墟 3 个状态。
- 严格顶部 90° 正交投影，只画屋顶与顶面；去除可见的正面山墙、立面和烟囱侧面。
- 建筑保留完整轮廓，在六边形内等比放大到最大可容纳尺寸，预留 4 像素边距，不按格子裁掉屋顶。完整、受损、废墟三种状态的轮廓合并计算统一定位与缩放，避免状态切换跳动或碎片被截断。
- 战场按 1.35 倍显示整张建筑画布，比此前 1.5 倍缩小 10%，仍允许屋顶延伸到六边形外侧。此放大发生在运行时，不会重新裁切资源；完整、受损、废墟共用同一比例。
- `rowhouses_l` 已重绘为六栋大小和朝向不同的住宅，包含错落巷道与私人院落，完整、受损与废墟状态保持同一布局。
- 废墟采用不均匀堆积的瓦砾、裸露尘土地面、塌陷坑和散落梁架；烟囱已倒塌、破碎，庭院不再保留完好的绿植与杂物。工坊使用破碎铁皮与扭曲金属梁架。
- 重绘石板和沥青材质，保留原有 13 种道路连接几何，对应 63 种方向组合。
- 同步游戏实际读取的城市地表材质；保持现有图片名、222×256 尺寸和 Cocos `.meta` 文件。

`manifest.json` 保存最终提示词、生成来源和项目内资源路径。`generated/` 保存原始生成图，`exports/` 保存建筑导出图。`before/` 保存被替换的原资源和地表材质包。

`city-preview.png` 是完整建筑图册。`neighbourhood-preview.png` 使用当前地表绘制器及游戏尺寸建筑，展示城市与现有树木和草地的效果。

在项目根目录运行 `node tools/installUrbanRedraw.cjs` 可重新导出。脚本检查图片透明度、六边形边界、道路出口及 Cocos 元数据，结果保存于 `validation.json`。
