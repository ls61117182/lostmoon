## 统一风格

延续略偏卡通的手绘桌游地形。正式素材采用垂直俯视、左上光源、短而柔和的阴影。
地面低对比，交互障碍轮廓较深。贴图不烘焙六角格线。
效果板存在较明显的物体侧面和偏密的石粒；正式制作时减少侧面表现，降低沙地颗粒密度，保留大形。

## 元素规格

| 元素 | 造型与配色 | 建议制作变体 |
| --- | --- | --- |
| 海滩底图 | 灰米色干沙，湿沙略深偏灰，少量宽缓风纹与碎石；不画强烈轮胎痕 | 干沙、湿沙、海岸过渡；先验证拼接 |
| 铁丝网 | 深灰粗线圈，短支柱，沿格边的窄条；不可把铁丝网画成整格围栏 | 完整、断开、压扁；直段、转角、端头 |
| 钢制拒马 | 三根交叉钢梁，保留工字钢翼缘；深炭灰加少量锈棕；缩小后仍呈立体交叉轮廓 | 完整、倾倒；少量朝向变体 |
| 沙堤 | 米黄浅色脊顶，棕灰坡脚，内陆侧稀疏橄榄绿草簇；圆润不规则 | 直段、缓弯、缺口、端头 |
| 混凝土海堤 | 冷灰规整顶部，深灰短侧面，低密度接缝和崩角 | 直段、转角、断口、端头 |
| 弹坑 | 不规则椭圆，深棕凹心，浅沙隆起边，少量散石；无火焰烟雾 | 小、中、大三种外形，避免规则圆环 |

地形底图和障碍物分层制作：沙地为连续底图；铁丝网、沙堤和海堤为沿边可拼接素材；
拒马与弹坑为独立叠加素材。需要透明背景的叠加物应重新生成透明素材，不从本效果板直接作为成品裁切。

## 正式素材验收

在实际游戏格子大小预览：底图不抢单位轮廓，铁丝网与拒马可辨认，
沙堤与混凝土海堤不混淆，弹坑边沿清楚且不误认水坑。
检查线性障碍在六个方向的衔接，检查底图拼接与海岸过渡。
