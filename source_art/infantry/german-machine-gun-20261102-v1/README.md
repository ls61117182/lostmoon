# 德国机枪班组 · 美术设计 V1

这套资源以现有 `Infantry01/02/03.png` 为美术参照，保留严格垂直俯视、灰蓝军服、灰绿钢盔、棕色携行具和粗黑轮廓。重机枪采用 MG42 风格的长枪身与展开支架，强调架设武器、协同供弹和充足弹药的视觉特征。

## 编组与接入建议

- 默认朝屏幕下方。机枪位于中前，副射手在其左侧，弹药手在右后方。所有成员随编组一起转向，保持供弹关系。
- 三名成员按同一个像素比例导出；不可把每张图强制缩放为相同长边，否则机枪射手会明显变小。现有步兵代码按长边缩放，`asset-manifest.json` 提供相对补偿比例及编组位置。
- 当前组合 72 像素画布内的有效轮廓约 60 × 54 像素；成员头盔约 7–9 像素。可整体显示，也可按清单坐标分层显示。独立分层时使用本设计编组，不直接套用普通步兵三角队形。
- 长枪身和展开支架是第一辨识点，副射手的供弹动作是第二辨识点，双弹药箱是第三辨识点。实际小尺寸以轮廓识别为主，穿孔和弹链节等细节仅在放大时出现。
- 表现强压制时，建议在枪口叠加短促连续闪光和间歇曳光，弹链/供弹手做轻微循环，射手整体仅做轻微震动。枪口位于主射手 PNG 约 `(104, 349)`，编组 PNG 约 `(324, 509)`；这些是美术参考点，接入时以实际枪口验证。

## 当前交付范围

本版本完成静态架设状态及三名成员的独立美术资源、透明编组和小尺寸检查。弹药手为携行姿态；主射手仍是架设姿态，因此整组不是完整的行军动画。收架行军、受压制、伤亡与逐帧开火动画尚未制作。

资源保存在 `source_art` 供审阅及后续接入；未注册新兵种、修改玩法数值或替换已有步兵素材。

复建导出与预览：

```powershell
node source_art/infantry/german-machine-gun-20261102-v1/prepare.cjs
```
