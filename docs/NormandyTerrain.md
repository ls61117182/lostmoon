# 诺曼底地形

已加入规则层、关卡加载、编辑器、格子说明、战斗表现与存档。
美术使用垂直顶视的原生绘制：沙地采用独立低对比材质，障碍物不显示立面。
实际绘制预览：`source_art/terrain/normandy-concept-20261013/runtime-topdown-preview.png`。
复现：`node tools/renderNormandyTerrainPreview.cjs`。

## 编辑器

欧洲战场新增“沙滩（欧洲）”刷子。选择格子属性中的“铁丝网 / 海堤 / 沙滩附加物”打开配置面板。
各方向铁丝网依次切换无、完好、损坏；海堤独立开关。沙滩格可独立开关拒马和弹坑。
切换为非沙滩底图会清除拒马与弹坑；切换为水域会清除铁丝网与海堤。“清空附加”清除所有新增属性。

## 数据

```json
{"t":"eb","wire":"102000","sw":"000010","sh":1,"cr":1}
```

`eb` 是欧洲沙滩，不是太平洋海滩 `B`。`wire` 为六位 0/1/2（无/完好/损坏）；`sw` 为六位 0/1。
方向与树篱一致：E、SE、SW、W、NW、NE。`sh` 和 `cr` 仅允许出现在 `eb` 上，可同时存在。
若共享边由两侧配置，只要任意一侧完好，该边即视为完好；坦克通过时碾坏两侧的完好标记。

## 规则

- 普通欧洲沙滩：移动成本及经典/硬核行动骰等效开阔地；禁止坦克隐蔽，不继承太平洋海滩的阵营与烟雾限制。
- 铁丝网：不挡视线；完好状态阻挡所有阵营步兵与反坦克炮跨越该边；坦克无需额外骰子，实际完成跨边移动后碾坏。损坏状态仅保留视觉。
- 钢制拒马：每格绘制三个；不挡视线，不阻止进入。任意阵营坦克进入后立即瘫痪，步兵不受影响。只在进入时触发，可按现有维修规则修复。
- 弹坑：沙滩底图保留，行动骰与移动成本等效泥地；步兵命中门槛 +1，坦克允许隐蔽。拒马与弹坑共存时两者效果均有效，既有“瘫痪不能隐蔽”限制仍然有效。
- 海堤：独立于原有 `bw` 的混凝土格边；跨越规则与防波堤相同，日军忽略，玩家坦克可以在杂项阶段前进跨越；不挡视线。
- 铁丝网损坏状态随存档与 PVP 状态同步保存；拒马瘫痪使用已有单位瘫痪字段。

## 验证

`node --test tests/NormandyTerrain.test.js` 覆盖六方向、两侧共享边、预览无副作用、碾坏、瘫痪、弹坑掩护、隐蔽、海堤、配置校验和存档恢复。
新增 10 项测试通过，其中包括直接调用战斗场景的步兵寻路和硬核反坦克炮移动方法，确认铁丝网在动画开始前阻挡移动。类型检查通过。
同时核对连续地形 CPU/GPU 材质与原有地形的回归测试。新增 GPU 材质保持旧材质编号，图集改为 5×5（1930×1930），着色器布局同步更新，并保持在 2048 纹理尺寸限制内。
`node tools/validateTerrainGpu.cjs` 的 WebGL 1 编译、WebGL 2 绘制及夏季/冬季/太平洋/诺曼底四组像素接缝检查通过，最大接缝误差为 0。

额外运行 `tests/enemyHardcoreTankDice.test.js` 时发现工作区已有的 CSV/生成文件不一致：硬核攻击表 CSV 的乘员字段与 EnemyAIDB 不一致。本次没有修改这两个数据源/生成文件，保留既有工作；该对照测试仍失败。
