# 主菜单与任务选择

主菜单保留原来的军事风渐变、地图网格和路线背景，按钮按参考图纵向排列：关卡、战役、联机对战、关卡编辑器、设置、测试功能。账号和说明保留在右上角。

## 关卡

`MenuOperations` 提供欧洲、太平洋、随机、自定义四个选项卡。欧洲和太平洋各有 12 个小关；列表支持滚动。选择小关只更新右侧预览，点击“进入关卡”才调用原有战斗入口。

地图预览直接读取关卡格子，保留空格、行偏移、地形、建筑和道路。预置关卡简介根据真实任务目标生成，以避开部分旧 JSON 简介中的乱码和编辑坐标；自定义关卡保留作者简介。敌军按初始配置统计。

随机关卡只有黑色占位格和“敌方兵力不详”，选择及预览不调用生成器。进入关卡后才生成实际地图。

## 战役和存档

战役页展示 `CAMPAIGNS` 中全部战役及各阶段地图预览。随机战役显示三段黑色占位地图。`GameSession.selectCampaign` 和 `resumeCampaign` 强制硬核模式；关卡模式偏好保存在 `MenuProgress` 中，不被战役修改。

- 关卡继续使用账号对应的 `SaveSlot`，兼容原关卡存档键。
- 战役进度使用同账号键追加 `:campaign_run_v1`，保存拼接地图、当前阶段、随机任务包、单位快照、升级和阶段检查点。
- 进入主菜单的关卡或战役入口时，仅在对应存档存在时显示“继续游戏 / 新游戏”。选“新游戏”或浏览预览不会删除旧档；实际进入新局并完成初始化后的自动保存覆盖对应存档。
- 回合开始与安全返回菜单时自动保存。战役选择升级后保存阶段检查点及独立进度。动画或敌军行动中的返回保留最近一次安全自动存档。
- 恢复存档时跳过新局开场回调，避免重置已保存的阶段和骰子。

## 测试工具

关卡编辑器作为正式功能从主菜单直接打开，不受开发工具开关限制；自定义关卡仍从关卡页的自定义选项卡选择游玩。

测试页集中提供坦克图片调试、坦克选择和测试地图入口，保留 `BuildProfile` 的开发工具开关。编辑器、图片调试和坦克选择均使用全屏子页；返回后显示原入口页面。

## 验证

`npm run typecheck` 检查类型。`tests/MenuCampaignFlow.test.js` 覆盖全部战役的硬核约束、随机地图及阶段恢复、单位和骰子快照、账号隔离、双存档互不覆盖与无效战役数据处理。

## 分辨率适配

所有页面共用等比例完整显示策略：背景覆盖整个窗口，主体保留 16:9 布局，较宽或较高窗口的剩余区域显示原背景。窄竖屏会缩小横向布局，不强行拉伸地图或文字。

分辨率刷新同时处理引擎 canvas-resize 和网页容器 ResizeObserver；后者解决百分比/vw/vh 容器改变像素尺寸但引擎未更新画布的情况。刷新回调使用 Array.from，兼容当前 Cocos 网页构建。
