# Pak 43/41 反坦克炮

单位 ID 保持 `pak43`。用户确认采用 B 型：8.8 cm Pak 43/41 L/71 双轮开脚炮架，并要求两条长支腿始终以 **V 形展开的射击姿态**显示。正常图、击毁图及转向过程中都保留这一姿态。

## 规则与参数

| 项目 | 配置 |
| --- | --- |
| 阵营 | 德军；默认绑定德军操炮步兵 |
| 穿甲 / 有效射程 / HE | 8 / 5 / 3 |
| 基础火力 / 装填难度 | 2 / 2 |
| 命中难度 / 装甲 | 8 / 4、4、2、2 |
| 朝向与移动 | 沿用 Pak 38 既有整炮转向和移动机制 |
| 图片姿态 | 双轮着地，两条长支腿向后张开，末端保留驻锄 |

火炮参数保持与项目现有虎王长 88 毫米炮同档，是游戏尺度映射。史料没有提供这些游戏整数值。该型号实物为有限方向射界的开脚炮架；游戏使用牵引式反坦克炮现有的整炮转向抽象，不再使用旧稿十字底座和独立全周回转层。

`isAntiTankGunKind` 沿用现有炮组规则：压制、击毙炮组、中立遗弃、步兵接管、AP 直接命中摧毁炮身、HE 炮身与炮组独立结算、等级与存档。单位不属于 `isImmobileGunUnit` 或分层坦克清单。未改变既有关卡或随机敌军池；可在关卡编辑器中选择。
