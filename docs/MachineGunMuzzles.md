# 坦克机枪枪口定位

入口：主菜单 → 测试工具 → 坦克显示调试器。

1. 在右侧选择车型，保持正常状态。
2. 点击「机枪定位：关闭」，进入同轴机枪定位；点击预览图中的同轴机枪射击孔。
3. 再次点击定位按钮，切换为航向机枪；点击车身上的射击孔。
4. 再次点击按钮退出定位。拖动车身、炮塔检查位置是否随对应部件转动；「炮口火焰」同时显示两种机枪的弹道参考线。
5. 参数列表顶部的四个枪口 X/Y 输入框可进行小数像素微调。青色十字表示同轴枪口，黄色十字表示航向枪口。定位时暂停预览震动，便于准确点击。
6. 先在项目目录运行 `npm run tank:debug-server`，再点击「保存配置」。保存会更新 `data/tank_visuals.csv` 并重新生成 `assets/scripts/core/TankVisualDB.ts`；重新进入战斗以使用新配置。

每种车型独立保存：

| 字段 | 坐标来源 |
| --- | --- |
| `coaxialMuzzleSpriteX/Y` | 分层坦克的炮塔 PNG；固定炮塔坦克的完整 PNG |
| `hullMuzzleSpriteX/Y` | 分层坦克的车身 PNG；固定炮塔坦克的完整 PNG |

坐标以原始 PNG 左上角为原点，X 向右、Y 向下，支持小数。无需换算到屏幕坐标、减去裁切偏移或手动计入缩放。枪口使用与显示部件相同的转轴、偏移、缩放和朝向变换。定位模式会将屏幕点击反算回源图坐标。

某种机枪的 X/Y 同时为 0 表示尚未校准，暂用原来的通用发射点。当前各车型初始值均为未校准，需要按实际贴图逐一定位；这不影响战斗中的武器规则。支持单独校准一种机枪。双机枪齐射时生成两条独立弹道；航向机枪单独开火时，枪口不会跟随炮塔偏转。步兵和对空机枪继续使用各自原有的发射位置。

战斗特效沿用本次攻击已选定的机枪类型：仅航向、仅同轴或双枪齐射。即使攻击前炮塔进行了部分转向，播放特效时也不会再授予一次转向并重新判定武器。该类型随骰子展示状态和联机动作一起传递，确保有无结果弹窗、战争迷雾内外以及远端显示一致。
