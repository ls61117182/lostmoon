# 谢尔曼基准单位属性与车组

配置源：data/units.csv。生成命令：node tools/buildUnitDB.js。

## 火力值

firepower为整数，允许负值，谢尔曼75毫米型为2。全单位配置统一从上一版减4，玩家在所有修正合计后取至少1颗；负基础火力不能提前截断。它表示车组分工与人机协同，不等于穿甲、高爆威力或装填速度。装填速度已独立为reloadDifficulty，谢尔曼为1。各单位最新数值、原型依据和离散档位见 [基础火力与装填难度分离](FirepowerReloadBalance.md)。

现有硬核模式使用两套规则：

- 玩家攻击骰数：当前火力值 = 基础火力 + 地形攻击修正 + 岗位加骰 + 战役强化修正，至少1；攻击骰数等于当前火力值。所有掷出的骰面正常使用。
- AI攻击骰：当前火力与玩家复用同一计算函数：基础火力+地形攻击修正+岗位加成+行动单位自身的战役强化修正，至少1；AI保留老兵+1、王牌+2等级加成，在取下限前合计。车长、炮手、装填手岗位可用各+1，车长关舱仍可加成，兼任及双装填手通过职责映射判定。每点火力提供3个有效骰面，每6个骰面组成一颗全有效骰，余数组成一颗部分有效骰；火力1为一颗1—3有效，火力3为两颗（6、3个有效面）。最低1火力保留一颗1—3有效的攻击骰。各骰阈值在掷骰时固定，排序不改变归属；移动与杂项骰不受此规则影响。实现见 `EnemyAI.hardcoreTankAIDiceCount` / `rollHardcoreTankAIDice`，验证见 `tests/AIFirepowerOverflow.test.js`。
- 专用AI牵引炮/重炮在主炮射击前进行同样阈值的火力检定；火力达到2直接通过（6个有效骰面）。操炮步兵的小武器攻击不受该检定影响。
- AI攻击骰 `attack1` 的1—6点均为“装填＞射击”，装填与射击的骰面级乘员条件全部为空。岗位伤亡仍影响当前火力及下一组骰的有效面，杂项骰的乘员条件与武器、装填、目标等通用合法性要求仍按原规则判定。
- 经典模式保留原行动规则。

## 装填难度（仅硬核模式）

单位表新增正整数 `reloadDifficulty`，默认1；它是当前装填值 `reloadProgress` 的上限。谢尔曼与普通M26为1，虎王 / 猎豹 / 象式为2，IS-2 / 猎虎 / 鼠式为3，SU-152为4，突击虎为8。所有可发射炮弹的单位均需配置；完整单位表和估档依据见 [基础火力与装填难度分离](FirepowerReloadBalance.md)。

每次装填推进1，达到上限才能发射，发射后归零。玩家换弹种先清零再+1；同种未满可继续，满后不能重复装填。同点骰装填只推进1。HVAP与炮射烟雾在完成装填时扣1枚，中途换弹不退库存，已装满未发射的有限炮弹换出才退回。AI攻击骰为“装填＞射击”，杂项4为“装填＞射击＞伏击”，装填不选弹种、不播放音效。

开局和新入场单位初始进度为难度−1；高爆威力大于穿甲值选HE，否则（包括相同）选AP，不扣有限弹药。突击虎为7/8HE，谢尔曼为0/1AP。战役玩家跨关原样保留进度、弹种和完成状态；读档恢复快照，不重新初始化。完整行为规格见 [主策划 §3.4 / §3.7](GameDesignDocument.md)。

## 乘员

crewMembers列存储实际人员，编号1车长、2炮手、3装填手、4驾驶员、5机电员/副驾驶、6第二装填人员。
crewRoleAssignments列存储兼任或可接替职责，如gunner=1;loader=1。伤亡作用于实际人员，行动能力通过职责映射读取。

- 九五式：1|4|5，共3人；车长兼炮手、装填手。
- 原型57毫米九七式：1|3|4|5，共4人；车长兼炮手。
- T-34/76：1|3|4|5，共4人；车长兼炮手。
- 三突G：1|2|3|4，共4人。
- SU-152：1|2|3|4|6，共5人；包括装填辅助人员，无虚构副驾驶。
- 鼠式：1|2|3|4|5|6，共6人；两名装填人员。
- IS-2：1|2|3|4，共4人；独立炮手，无副驾驶。
- 突击虎：1|3|4|5|6，共5人；车长兼炮手，两名装填手。
- 猎虎和象式：1|2|3|4|5|6，共6人；两名装填手。
- 其余已配置坦克保持相应5人车组。

任务生成、增援、补员、读档和联机单位恢复均使用实际车组配置。第6名乘员参与伤亡和弃车判断，界面显示对应图标。

## 潘兴

m26_pershing保留兼容ID，显示名称为M26潘兴，按欧洲战场90毫米M3配置：AP5、HE3、射程4、火力2、装填难度1。此次没有替换已有美术资产。
