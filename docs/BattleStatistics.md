# 战斗结束报告

胜利和失败共用 `BattleOutcomePanel`，采用深绿战报面板；胜利用金色、失败用红色强调。统计对象为本地玩家的主角坦克，不含 AI 队友。

| 显示项 | 统计口径 |
| --- | --- |
| 受到攻击 | 每次对主角坦克完成的攻击判定，含未命中 |
| 被命中 | 上述攻击中 `hit=true` 的次数 |
| 被击穿 | 上述攻击中实际进入穿甲判定且成功击穿的次数 |
| 主炮命中率 | 成功命中判定 / 全部主炮命中判定 |
| 主炮击穿率 | 成功击穿 / 命中后实际进入穿甲判定的次数 |
| 机枪命中率 | 成功命中 / 机枪独立攻击判定次数 |

- 百分比四舍五入为整数，并同时显示分子和分母；没有判定时显示「—」，有判定但全失手时显示 `0%`。
- 自动命中的普通 HE 步兵攻击、重炮碉堡普通攻击不进入主炮命中率。HE 另行进行的命中检定计入；威力检定不当作穿甲检定。
- 碉堡精确射击以 `shootingPortHit` 判断命中检定成功与否；射孔未命中后命中碉堡本体的后续穿甲判定仍进入击穿率。
- 直接命中摧毁的反坦克炮、射孔命中直接摧毁等，没有穿甲检定，不进入击穿率。过穿仍属于成功击穿。
- 双机枪按两份独立报告计数；不可能命中的扫射仍计一次失败。HE 同格波及不增加主炮射击数，烟幕弹不计入。
- 受攻击包括正常射击、伏击、相邻步兵集火、狙击、空袭、迫击炮和实际触发伤害判定的地雷；空袭被击落、天气导致仅飞越，以及没有合法目标的事件不计。
- 数据在攻击实际结算时写入，不在掷骰预演和历史战报回放时写入。PVP 收到的远端攻击单独记录。
- 统计随存档与战役检查点保存。战役前进到下一小关继续累计；重试小关恢复检查点时的统计，重开普通关卡归零。旧存档没有该字段时从零累计。

布局预览由真实组件的节点和文案生成，用于核对中英文间距；最终效果仍需在 Cocos 运行时确认。
