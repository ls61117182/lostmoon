# 《美国坦克王牌》中文规则指南

American Tank Ace: Europe, 1944–45 · 阅读与查表辅助

整理日期：2026年10月22日。

本文以独立表述概括游戏机制，按游玩中的决策组织内容，是中文规则摘要，不是官方译本或逐页全文翻译。依据本地英文规则书 v04e、2022年12月5日官方勘误，以及已核对的任务表和事件标记。未取得完整表卡的部分只说明查表方法，不补写概率或结果。

## 1. 先理解整局游戏

玩家扮演一名美军坦克车长，管理自己的坦克和五人乘员组，在欧洲战场连续执行任务。战役通常从1944年6月推进到1945年4月底，也可选择较晚开始。

游戏有三个时间层次：

- **战役日历**：任务日志每格代表一次主要任务机会，不等于每天固定打一仗。
- **任务／战斗**：一次进攻、防御等行动，可以包含许多战斗轮。
- **战斗轮**：车长分配有限指令，敌军行动，随后检查事件。

车长阵亡会立即结束生涯。伤病导致下一次可出勤日期超出1945年4月，也会结束游戏。达到31次成功任务不会提前结束，仍按生涯终点结算。

| 成功任务总数 | 最终评级 |
|---|---|
| 0—4 | 失败 |
| 5—10 | 平局 |
| 11—20 | 有限胜利 |
| 21—30 | 重大胜利 |
| 31及以上 | 决定性胜利 |

任务日志中1944年6月有6格，随后每月8格，共86格。整补、伤病、维修会占用日历，反击又可能追加战斗，所以86格不能直接当成86场战斗。

## 2. 开始生涯时准备什么

选择当时已经可用、且声望等级允许指挥的坦克，准备对应车辆卡、乘员记录和任务日志。师或其他部队标记在基础玩法中主要提供历史背景。

按F1训练表完成诺克斯堡训练；毕业提供1个初始经验点。训练还可能带来指定技能的购买优惠或其他效果，按F1逐项处理，不把这些结果当成已经买到的普通技能。

出战前需要记录：车辆型号、武器状态、车体和炮塔朝向、开闭舱状态、膛内炮弹、就绪弹架配置、有限弹种、机枪当前弹药、技能及其使用状态。

游戏提供九种谢尔曼配置和M26潘兴。选车时直接读取该型号车辆卡上的装甲、火力、弹架、装备、出现日期及声望要求；不要用历史资料中的实车参数覆盖游戏数值。

## 3. 每进入一个任务格

按当前月份查A1确定任务，再查A3天气、A5地形、A4敌军编成与装备、A6敌步兵质量。敌单位随机布置到战斗板的A、B、C区；A、C在外侧，D、E是侧翼位置。

敌编成中的同一项“2辆坦克”按该项一次型号结果生成同型车辆。同场敌步兵质量只掷一次，各步兵单位共用该结果，这是官方勘误的明确说明。

初始距离：树篱与城镇为近距离，森林为中距离，其余通常为远距离。

### 五类基础任务

| 任务 | 影响战斗的条件 |
|---|---|
| 接敌推进 | 开局1D6为1—2时敌军未构筑阵地，其余按有阵地处理；A、C区敌车辆在德军第一次行动时，若可能，会向D、E推进。通常玩家先行动。 |
| 进攻 | 敌步兵掘壕；德军只在第一轮先行动；结束后检查反击。 |
| 强攻 | 敌步兵掘壕、敌车辆车体遮蔽；玩家获得立即结算的开场野战炮兵火力，然后德军在第一轮先行动；敌车辆除卡车外不移动；结束后检查反击。 |
| 防御 | 玩家可车体遮蔽开局；敌军接近并向侧翼推进，每轮结束缩短距离，直到近距离。勘误：敌反坦克炮换成同数量自行火炮；玩家一次后退就能退出任务。 |
| 整补 | 不展开战斗，在当前格记整补，进入下一格；§7.1.5明确将其计作成功任务。 |

规定月份放置标记；抽到对应编号且标记有效，才算直接参加。尚未生效、已参加或已过期时，只执行基础任务。每个事件只能参加一次，参加后移除；有效期内没抽到，就会错过。

成功完成有效历史事件任务获得1个完整经验点，代替通常的一次任务经验进度；失败仅保留普通一次任务的经验进度。历史事件仍只算一次成功任务，并没有自动变成三次胜场。事件本身也没有另设固定敌军和专属地图。

## 4. 战斗中真正稀缺的是车长指令

通常每轮全车共用车长的**2条指令**，不是五名乘员每人各有2条。指令可以逐条决定和执行，无须先公布整轮计划。例如第一炮已经击毁目标，第二条指令可以改做其他事情。

主炮射击命令包含炮手射击和装填手随后的装填工作，装填不另花一条车长指令。同轴机枪由炮手操作，可以在装填手填充弹架时射击。

| 车长可安排的行动 | 需要留意的条件 |
|---|---|
| 主炮射击、再次射击同一目标 | 受膛内弹种、就绪弹架、炮塔转向等限制；连续校射同一目标可取得规则中的修正。 |
| 同轴机枪射击 | 炮手操作；转动炮塔后，该轮同样受到只能射击一次的限制。 |
| 补充或调整就绪弹架 | 装填手通常一轮处理4发；有关并行动作见下一节。 |
| 前进、后退、寻找车体遮蔽 | 改变距离或防护状态，并按相应表格检查无法移动风险。 |
| 改变车体朝向 | 改变正侧面受弹关系，以及车首机枪可攻击的区域。 |
| 机动争取侧射 | 获得侧射机会，同时可能暴露自身侧面；目标已经无法移动时效果可持续更久。 |
| 车首机枪射击 | 副驾驶操作，受车体朝向约束。 |
| 车顶.50机枪射击 | 车长操作，必须开舱。 |
| 2英寸烟幕发射器 | 有该装备的车辆由装填手使用，向自身位置放置烟幕。 |
| 呼叫间接火力 | 正常呼叫要求可用的指挥电台。 |
| 开舱、闭舱 | 可影响一名或多名适用乘员；闭舱影响观察与作战效率。 |
| 换出膛内炮弹 | 将不合适的已装填弹换成弹架中的另一发。 |
| 单独转动炮塔 | 官方勘误新增P行动，不射击；不能与填充弹架在同轮并行。 |

清除卡壳、机枪换弹、被击毁后的逃生等有自动处理机制，不能简单都视为免费且无时间成本：它们会占用相应乘员的工作，并可能被新指令打断。

## 5. 主炮、机枪与就绪弹架

膛内炮弹、就绪弹架、车内储备是三件事。射击打出膛内已有的一发，随后装填手按规则装入下一发。弹架提供快速取弹的来源。

- 弹架空时，每轮最多下达一次主炮射击命令，即使车长还有指令。
- 补充弹架通常一轮处理4发，也能卸出旧弹或混合调整配置；不能超过该车型容量。
- 装填手在完整进行该轮填架工作时不兼做其他职责；主炮命令需要他参与，不能把主炮射击理解为炮手独立完成。
- 原文也允许填架被射击命令打断。因此，对于“先射击再填满4发”等同轮时点争议，本指南不把它当作已获官方确认的组合；按§4.4与§7.2C的工作占用限制处理。
- AP和HE在本游戏中不逐发跟踪总储备；WP、HCBI和APCR等特殊弹种受车型规定数量限制。

| 弹种 | 主要用途 |
|---|---|
| AP 穿甲弹 | 对装甲车辆；不能拿来有效杀伤步兵和反坦克炮组。 |
| HE 高爆弹 | 对软目标；命中坦克／自行火炮主要迫使其闭舱，不按常规穿甲弹摧毁。 |
| APCR／HVAP | 强化穿甲弹，所有距离穿深额外+1；游戏中两名称指同类弹药。 |
| WP 白磷弹 | 兼具烟幕和杀伤效果；对装甲车辆还有特殊弃车判定。 |
| HCBI 烟幕弹 | 放置Smoke 2，不产生通常的人员杀伤；按勘误无需B1命中检定。 |

**机枪职责不要混淆：**同轴机枪由炮手射击，装填手换弹；车首机枪由副驾驶射击和换弹；车顶.50由车长射击和换弹。武器维护技能的归属另按技能规则，装填手的该技能作用于.50，不代表他负责操作.50。

## 6. 如何理解命中、防护与伤害

对装甲目标的主炮攻击，通常先查B1命中，再查B3命中部位与穿甲结果。穿深会受到距离、弹种等修正；比较穿深与本次实际命中的装甲面。软目标和机枪／间接火力主要使用B2，并遵守目标与弹种注释。

车体与炮塔朝向分开记录。同一来弹方向，可能击中车体侧面，却击中炮塔正面，不能把整辆坦克只按一个朝向判断。

车体遮蔽使车辆更难被命中，并让有效命中落在炮塔；玩家防御任务可直接拥有该状态。移动后会失去遮蔽，单纯调整车体角度例外。遮蔽时不能使用车首机枪。寻找遮蔽的驾驶员地形技能修正按勘误为B5a的+1。

开舱有利于观察和操作，但暴露乘员可能受机枪、炮击等伤害。闭舱不等于不会遭受穿甲、剥落或其他车内伤害。B1中“射手闭舱”的修正取决于车长状态。

烟幕既降低射入区域的效果，也降低从区域内向外射击的效果。每轮开始Smoke 2降为1，Smoke 1移除；叠加发射不会超过Smoke 2。

非贯穿命中也可能造成震慑，消耗当前或下一轮的一条指令。穿深足够却未贯穿时，还可能出现装甲内表面剥落并伤及乘员。敌坦克／自行火炮也受震慑，但不为其逐人检查剥落伤。

车辆伤害使用DE、IMM等结果，不采用逐点扣生命值。无法移动后仍可能射击，但不能靠战斗中的一般移动命令修复。步兵通常有两级兵力：减员会翻到减员面，再减员则移除；同轮重复压制也可能转化成额外损失。

## 7. 敌军、事件与任务何时结束

游戏把其他友军抽象化处理，敌军不一定一开始全都攻击玩家。未锁定玩家的敌单位每轮按规则检查目标；普通规则中1D6为1时开始攻击玩家。一旦锁定，不需每轮重新掷骰决定是否继续。被玩家射击的敌单位也会按规则转向玩家；纯HCBI烟幕不引发同样反应。

反坦克炮在第一轮有发现限制：通常不能主动攻击尚未向你开火的炮；第二轮起限制解除。敌军乘车步兵的下车占用首轮行动，不能把运输车和搭载步兵当作开局便可同时射击的两支独立火力。

每轮更新烟幕、火力支援倒计时与压制等状态，按任务的先后手规则进行行动，结算敌军目标和攻击，最后检查B9事件。敌军已经全部离场时不再掷事件，避免继续刷出增援。

需要区分三类东西：

- **历史事件**：由A1和月份标记触发，主要改变战役经历及经验收益。
- **轮末事件**：B9产生，可能改变当前战况。
- **随机事件**：同一任务第一次在B9掷出12时，转入随机事件；后续12按雷区规则处理。每任务随机事件最多一次，雷区也最多发生一次。

任务通常在敌军全部被消灭或移除、玩家坦克被毁，或玩家撤离时结束。只剩一个敌步兵单位时，它会撤退或投降，任务结束。主动撤离判失败；按勘误，驾驶可作战车辆退出还不获得该次任务经验，并给下一次晋升尝试累计+1修正。

### 连续反击

进攻或强攻结束、坦克仍能作战时，1D6掷出6触发德军反击。重新布置敌军，由玩家执行防御；天气、地形不变，中间没有补给。

反击不另占任务日志一格，已用技能不刷新，无法移动状态延续；经验上算第二次任务，勋章所需击毁数则与前一场合并。

## 8. 乘员伤亡与岗位接替

受伤来源包括暴露状态下的火力、穿甲后的逃生、装甲剥落等。B／相关结果并不一律直接阵亡；先按对应结果判断谁可能受伤，再查B7伤势。坦克DE时还需要按B6处理起火与逃生。

| 状态 | 处理重点 |
|---|---|
| 轻伤 LW | 车长每轮少一条指令并停用技能；其他轻伤乘员停用自身技能。下次任务开始移除轻伤。 |
| 重伤 SW | 不能工作；战斗持续时每轮末掷2D6，11—12伤重死亡；任务结束查重伤恢复表。 |
| 阵亡 KIA | 不能工作，个人技能丢失；车长阵亡结束生涯，其他岗位战后补员。 |
| 伤重死亡 DOW | 是重伤后死亡的结果，不是能继续工作的独立伤势等级。 |

车长重伤时炮手临时指挥，每轮只有一条指令；驾驶员或装填手重伤时，副驾驶可在规则规定的中断后接替。炮手重伤后，车长接替射击，主炮效率下降并视作闭舱。副驾驶接替其他岗位意味着无法同时承担原来的车首机枪职责。

重伤缺勤达到规定期限时会引入新乘员。新乘员不继承前任技能，但按勘误先接受诺克斯堡训练。车长长期住院还可能导致换车及整组乘员变更。

勘误明确：重伤乘员不能自行从DE坦克中逃出，不能照普通乘员掷逃生就算救出。主动弃车、伤员搬出等按专门条款处理。

本指南未取得完整B6、B7、C2表卡，故不列出“每个伤势点数”的整张表；不要把某一特殊逃生后的受伤分布推广成所有受伤场景的通用概率。

## 9. 技能、晋升与换车

一般完成三次任务累计获得1经验点，普通任务成败都可计入；因伤病、修理等跳过的任务不算。有效历史事件成功可直接获得1点。大部分限次技能每任务刷新一次，连续反击不刷新。

下表概括九种可购买技能；训练表中的其他效果不自动加入购买清单。

| 技能 | 经验点成本 | 作用摘要 |
|---|---|---|
| 炮术 Gunnery | 4 | 持续改善炮手的命中及相关火力判定。 |
| 瞄准弱点 Aim | 2 | 把B3标有IMM**的指定结果转换为摧毁，不能泛化为所有IMM。 |
| 第六感 Sixth Sense | 1 | 每任务一次，在来火伤害抵达前及时闭舱。 |
| 专家 Expert | 3 | 每任务一次重掷自己的攻击或命中，必须接受新结果；按坦克系列适用。 |
| 协同 Synergy | 首次2、重新建立1 | 每任务选一轮把车长指令从2增到3；关键乘员损失可使协同丢失，重购还有获得新经验等条件。 |
| 领导力 Leadership | 1 | 改善晋升检定。 |
| 地形眼光 Eye for Terrain | 2 | 驾驶员持续改善无法移动／寻找遮蔽的相关检定；B5a修正按勘误。 |
| 肾上腺素 Adrenaline Rush | 1 | 每任务一次，填弹架可处理6发，而非通常4发。 |
| 武器维护 Weapons Maintenance | 每项1 | 指定乘员对应的机枪忽略该任务第一次卡壳；按实际购买岗位分别记录。 |

技能属于具体乘员。轻伤会限制使用，阵亡、离队可导致技能或训练优惠丢失；不要只在坦克卡上保存技能而忽略持有人。

经验用于技能；声望分数是可消费资源；声望等级是累计资格。花掉声望分数不会降低声望等级，等级最高只需跟踪到5。

勋章和晋升可提供声望，但有首获、重复授予和同任务只取最高英勇奖等限制。不能把“每拿到一个勋章都加一点”当成无例外通则。具体授勋门槛查§8.1。

通常每服役两个月尝试晋升一次。初始为Staff Sergeant，军衔依次提高至Captain；官方勘误指出二战时期第二级军衔应称Technical Sergeant。1st Lieutenant与Captain的指挥电台会解锁正常间接火力呼叫。

换车同时受出现日期、声望等级和消费影响：原车被毁后升级通常花1声望分；原车仍能作战却主动升级通常花2分；被毁后免费补回同型号也是选择。2分还可用于按规则请求伤愈老乘员归队。

## 10. 支援与战后整理

正常呼叫迫击炮或野战炮兵要花车长指令，且需要可用指挥电台。迫击炮以CFF 2、野战炮兵以CFF 4开始倒计时；并非呼叫后立刻命中。

普通支援额度为每任务两次迫击炮或一次野战炮兵。强攻的免费开场炮火，以及按规则战前花声望购买的额外野战炮兵，不占普通额度。强攻免费炮火无需自己的指挥电台；通过战利品获得额外迫击炮不因此豁免电台要求。

官方提供可选的区域火力处理：先指定区域，结算时打击当时位于该区的目标。使用这一可选规则时，不能继续按最初指定的某个单位追踪弹着。

战后先确认反击，再整理任务结果、击毁归属、乘员伤势、修理、勋章、经验和补员。获胜并占据战场时可查W1搜集战利品，再按W2兑换；战利品不是声望分数，兑换多付不找零。车辆被毁时携带的战利品按勘误丢失。

无法移动的车辆战后掷1D6，1—2会缺席下一任务维修。车辆被毁也会损失下一任务机会以换车补员；这类缺勤与A1抽到的“整补成功”要分别记账。

## 11. 可选玩法与使用边界

基础规则书含合作、竞争和提高威胁锁定概率等可选规则。合作模式共享任务、天气、地形及步兵质量，但各自生成敌军；清空自己战场后才能按相邻区域规定支援同伴。竞争主要比较最终车辆／反坦克炮击毁数。不要默认把这些选项混进基础单人生涯。

要实际完成所有判定，仍需配套表卡。尤其是A4敌军完整生成、B1—B7的所有点数结果、B9事件、C类表、F1训练和W1／W2，本文没有完整重建。实际游玩遇到本指南未列数值时，查原表，不自行推测。
