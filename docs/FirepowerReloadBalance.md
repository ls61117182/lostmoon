# 基础火力与装填难度分离（2026-10-12）

配置源：[units.csv](../data/units.csv)。生成命令：`node tools/buildUnitDB.js`。

## 设计尺度

谢尔曼75毫米型为 **基础火力2、装填难度1**。基础火力表示车组分工与人机协同，影响硬核模式攻击骰；装填难度表示完成一发炮弹装填所需的动作次数。火力既不是炮弹威力，也不再用作重炮慢装填的代替参数。

- 火力2：车长、炮手、装填岗位独立，通常是五人车组。六人双装填手仍为2，额外装填人员的作用体现在装填流程与岗位接替，不自动获得更高基础火力。
- 火力1：四人但指挥、瞄准、装填岗位仍独立，如三突G、IS-2；突击虎虽有五人，但车长兼炮手，取1。
- 火力0：四人车组、车长兼炮手，如T-34/76、原型57毫米九七式。
- 火力−1：九五式三人车组，车长还承担瞄准和装填，任务集中于一人。
- 非坦克炮班不按坦克人数套公式；开放炮位与独立分工按中性协同基准2。步兵和卡车同样减4，使用火力−4占位，不参与坦克火力骰池。

装填难度采用离散设计档位，以下数字都是本游戏的推定值，**不是史料给出的数值，也不是严格的秒数或射速倍数换算**。比较的是已在车内的弹药到下一次可射击的装填过程，不把外部补充弹药、行军故障或乘员训练水平再算作固定装填惩罚。

| 难度 | 设计含义 |
| --- | --- |
| 1 | 常规小中口径整装弹；谢尔曼基准。一个动作即可装好。整数下限无法表达比谢尔曼更快的炮。 |
| 2 | 较大整装弹或很长的高初速炮弹：虎王/猎豹/象式的长88毫米。此档是重量、长度与车内搬运的保守综合估档。 |
| 3 | 122/128毫米重弹；IS-2和猎虎的分装程序、鼠式试验车的重弹处理。两名装填手改善协同，但仍不能按小口径一动作完成。 |
| 4 | SU-152的152毫米重型分装弹；搬运及送弹负担更大。 |
| 8 | 突击虎380毫米火箭弹的多步骤重物处理。保留显著慢装填特征，同时压缩极端历史时长，避免机械照搬造成不可用单位。 |

常规37/50/57/75/76/85/88毫米L56的细微射速差异落在同一档。T-34/76和九五式已由基础火力体现兼任岗位负担，不因为同一指挥负担再提高装填难度。豹式75毫米L70也不因为长炮管本身自动升档。上述选择以车内实际处理流程为依据，口径不是唯一判断条件。

## 车组纠错

IS-2实际四人为车长、炮手、装填手、驾驶员，将原有虚构副驾驶去除，`crewMembers=1|2|3|4`。车长承担通信职责不等于兼任炮手，所以火力1而非T-34/76的0。[IS-2车辆资料](https://en.wikipedia.org/wiki/IS-2)

突击虎采用五人编制中车长兼炮手、驾驶员、通信员、两名装填手的解释：`crewMembers=1|3|4|5|6`，`gunner=1;loader=3|6`。资料对岗位称呼存在差异，游戏明确采用这一编制；五人总数和重弹搬运流程由博物馆资料支持。[突击虎岗位编制](https://en.wikipedia.org/wiki/Sturmtiger)、[博物馆车辆资料](https://tankmuseum.org/article/vehicle-sturmtiger/)

`jagdpanther`按Jagdpanther猎豹原型评估；现有显示名“追猎者”保留作为项目命名，不把它误按四人Hetzer设计。

## 史料依据与局限

史料支持结构、分工和弹药流程；本页表内全部游戏数值是据此作出的设计判断。

- [The Tank Museum：Soviet Tanks at Kursk](https://tankmuseum.org/article/soviet-tanks-kursk/)：T-34/76的两人炮塔与后来的T-34/85三人炮塔区别。由此支持指挥与瞄准分工改善，不能直接把人数换算成射速。
- [The Tank Museum：Ha-Go](https://tankmuseum.org/tank-nuts/tank-collection/ha-go/)：九五式狭小的车内操作空间；配合三人编制解释多重职责负担。
- [The Tank Museum：The Sturmtiger's Firepower](https://tankmuseum.org/article/sturmtigers_fire_power/)：345千克火箭弹，外部吊装补给、车内滚轮装填托盘，以及开膛前的通风流程。本游戏装填8依据车内搬运和流程复杂性，不把每发都错误地视为从地面吊入车内。
- [美国战争部1945年敌方兵器目录：猎虎及象式](https://www.lonesentry.com/ordnance/2009/12/page/4/)：猎虎128毫米炮使用分装弹、六人编制；象式长88毫米炮及六人编制。原始战争时期目录也存在观测误差，不用于改写本轮以外的装甲等属性。
- [美国战争部1945年90毫米M3弹药说明](https://www.lonesentry.com/manuals/90-mm-ammunition/index.html)：T26E3/M26的90毫米M3弹药采用整装弹；普通M26归装填1，不将瞄准射速直接当作装填时间。
- [Tank Archives：IS-3 Reloads](https://www.tankarchives.com/2014/12/is-3-reloads.html)：引述试验与书目，说明便于取用的弹位与持续装填有差异，SU-152也不能只用一个峰值射速描述。用于提示样本差异，不将其IS-3具体测时套用成IS-2数据。
- [Tank Archives：The Elusive Maus](https://www.tankarchives.com/2022/12/the-elusive-maus.html)：试验车重弹搬运和双装填人员设计；鼠式装填3属于原型估档。
- [SU-152技术资料](https://il2sturmovik.com/museum/vehicles/su-152-chkz-1943/)：五人车组与ML-20S分装弹、重型弹体；这是模拟产品的资料汇编，作为补充来源，不当作原始试验报告。

## 生效规则

装填难度仅用于硬核模式，完整行为规格以 [主策划 §3.4“装填难度与装填进度”](GameDesignDocument.md) 为准。当前装填值不能超过难度，只有达到上限才允许主炮发射；发射后进度归零并清空弹种。玩家每次装填推进1，换弹种先归零再+1；同种未满可继续装填，满后按钮禁用。AI装填不选弹种，发射时选弹，装填不播放音效，玩家装填音效保留。攻击骰1—6为“装填＞射击”，各点数的装填与射击均取消骰面级乘员存活要求；岗位伤亡仍影响当前火力及下一组骰的有效面。杂项4为“装填＞射击＞伏击”，保留炮手存活要求，装填动作不能同一骰接着射击；同点骰装填虽然消耗两颗骰，也只推进1。火力仍影响硬核攻击骰数及有效骰面，不随乘员伤亡修改静态配置；运行时伤亡与岗位接替继续使用原乘员规则。

有限弹药在装填达到上限时才扣除1枚：例如1/2HVAP仍保留原库存，2/2HVAP扣1枚。中途换弹不退弹，因为尚未扣除；已装满且未发射的炮弹换出时按原规则退回库存。

新入场初始化仅在硬核模式生效：所有单位装填值为装填难度−1，高爆威力严格大于穿甲值时预选HE，否则预选AP；不扣有限弹药。突击虎为7/8HE，谢尔曼为0/1AP。开局与增援使用同一规则，读档恢复保存进度；战役玩家跨关保留当前装填值和弹种，不重新初始化。
