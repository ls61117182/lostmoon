# 硬核模式过穿美术表现设计

概念稿：`docs/ui/overpenetration-vfx-concept-v1.png`

## 设计目标

- 玩家在缩放后的俯视地图上能在 0.3 秒内区分“过穿”“正常击穿”和“跳弹”。
- 过穿强调弹芯沿原方向穿出，不能出现偏转弹道、大火球或整车爆炸，避免误读为跳弹或击毁。
- 表现不依赖目标车型的独立贴图，坦克、突击炮、卡车共用同一套程序化特效。

## 分阶段表现

1. **入射（0–0.14 秒）**：沿现有主炮曳光轨迹飞向目标；命中点出现半径约 `0.10 × hexSize` 的白黄高亮和 5–7 条短火星。
2. **贯穿（约 0.06 秒）**：炮弹抵达车体入口后立即隐藏，入射点只保留紧凑火花；隐藏期间表示弹芯正在车体内部穿行，不能在单位贴图上方绘制曳光线。
3. **穿出（随后约 0.20 秒）**：弹芯直接从以目标中心镜像计算出的另一侧出口重新出现，再继续飞出约 `1.35 × hexSize`。出口轨迹以白热芯、橙色外辉表现，并带 3 股窄幅高温碎屑喷流；出口尾迹按已飞距离逐渐增长，最远只能回溯到出口，不能倒伸回车体。碎屑扩散宽度不超过 `0.11 × hexSize`。
4. **结果反馈**：穿甲行显示琥珀色“过穿”；若起火/击毁被取消，伤害行显示“起火（过穿无效）”或“击毁（过穿无效）”，目标格浮字显示“过穿”。若同组仍有炮塔、乘员等有效结果，继续显示并执行这些结果。

## 色彩与层级

- 弹芯：`#FFFABE`；入口闪光：`#FFFFE8`；出口喷流：`#FF7426`；火星：`#FFCA3A`；碎片：`#2B2925`。
- 特效位于单位本体之上、战争迷雾之下；只有攻击双方按现有规则可见时才显示完整轨迹。
- 不给目标附加持续燃烧、橙色受损染色或残骸切换；这些视觉状态只由最终有效伤害决定。

## 声音建议

- 复用现有击穿金属声作为入口层，音量保持不变。
- 后续可叠加一条 80–120 ms 的高频“撕裂/啸叫”短音作为出口层；不要使用爆炸低频，以免和击毁混淆。
