# 雾天效果首版

欧洲战场第一关 `assets/resources/missions/mission_01.json` 当前设为 `weather: "fog"`，用于查看效果。关卡编辑器天气选择也支持“雾天”。雾天下，敌我坦克（含固定炮突击炮）的车长开舱视野、炮手视野均固定为 2 格，包括有视野强化的车辆；车内关舱环形视野、步兵和其它非坦克单位原有视野不变。烟幕和地形仍进一步限制实际可见范围，无线电共享规则保持原样。雾天不增加命中或移动惩罚；仅晴天的空降支援不在雾天下触发。

雾天烟幕额外阻断直接观察：烟幕格内单位只保留自身所在格的直接视野，烟幕格外单位不能直接看见烟幕格及格内单位，烟幕仍阻挡后方视线。该限制在各单位自身直接视野计算时应用，无线电共享仍在其后按原有收发条件合并；因此烟幕内单位仍可接收队友视野，烟幕内有发送能力的队友也仍可共享自身所在烟幕格。不会对共享后的最终视野再次按烟幕过滤。所有天气下，共享情报只用于侦察显示和转向，不能代替射击单位自身的直接视野；主炮、机枪和步兵攻击均需在开火时直接看见目标，完好炮塔按转向目标后的自身视野检查。雾天烟幕内单位无法借共享情报向外射击，外部单位也无法借共享情报射击烟幕格内目标。同格步兵攻击与炮射烟雾的原有规则保留。晴、雨、雪天气的烟幕规则沿用原有行为。

雾天恢复正常锁定射击：玩家、友军与敌军坦克主炮（AP/HVAP/HE，包括伏击）命中敌方坦克后可建立锁定，后续射击获得命中阈值 -2 加成，并显示锁定瞄准圈；消耗、续锁与失效条件与其它天气一致。

`FogWeatherRenderer.ts` 缓存真实六角格轮廓，以 `Mask.Type.GRAPHICS_STENCIL` 裁剪单个雾层 Sprite。Sprite 仅使用 1×1 不透明白色纹理，地图边界不再采样低分辨率二值覆盖贴图，避免斜边放大后出现锯齿和外溢尖齿。冷灰蓝色为 RGB(194,207,214)，底雾随离玩家的六角格距离增加：本格格心 5%，每增加 1 格增加 10%（1 格 15%、2 格 25%、5 格 55%），再叠加最多 20% 流动雾，最终透明度限制在 0～100%。使用连续轴向距离在格心间平滑过渡，无逐格硬边。渐变中心跟随玩家坦克的实际移动动画，不跳到目标格。

`weather-fog.effect` 生成两层大尺度、不规则柔软雾纹，约 30 秒和 55 秒移动一个相邻格距离。流雾附着地图坐标，随地图平移、缩放与旋转，不使用屏幕上远下近的渐变。

裁剪轮廓只在更换地图时生成；镜头移动和缩放仅改变节点变换，雾的流动只更新材质参数。覆盖范围裁切至实际地图格，单位名称、状态、攻击概率和 HUD 位于其上。天气雾与战争迷雾分别绘制，单位是否可见由视野规则决定；退出场景释放裁剪节点、材质、纹理和 SpriteFrame。

调节色彩使用渲染器中的 `sprite.color`；`params.set(time, 0.05, 0.20, 0.10)` 的后三项依次为本格底雾、流动雾幅度、每格底雾增量；`fogOrigin.xy` 为玩家在地图中的归一化位置（单位为六角格半径）。调节速度、雾带尺度使用 shader 中的 `windA`、`windB` 与坐标缩放。

验证：`npm run typecheck`；`node --test tests/FogWeather.test.js tests/FogWeatherFootprint.test.js tests/WeatherVisual.test.js tests/BattleSceneWeatherEffects.test.js tests/levelEditorWeather.test.js tests/FogOverlay.test.js tests/AirborneSupport.test.js tests/AirbornePresentation.test.js`；`node tools/validateWeatherFogGpu.cjs`。

GPU 验证使用生产片元 shader、真实六角裁剪顶点和第一关地图范围，在 WebGL 1/2 检查游戏尺寸下地图外零雾像素、接缝无裂缝、浓度变化、逐帧连续性与长期流动，结果写入 `tmp/weather-fog-gpu/pixel-result.json`。SwiftShader 结果用于正确性检查，实际观感与性能以 Cocos 预览为准。
