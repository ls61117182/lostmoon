# 步兵视觉朝向设计

## 目标

普通步兵、日军步兵、美军步兵与军官在移动或攻击时面向动作方向，并在动作结束后保持该视觉朝向。此功能仅改变战场表现，不改变战斗规则、单位数据、存档或网络协议。

## 范围

- 移动开始时，按移动起点到终点的方向更新视觉朝向；移动过程中和结束后均保持该方向。
- 攻击开始时，按攻击者到目标的方向更新视觉朝向；攻击结束后保持该方向。
- 三人步兵小队中的三个 Sprite 使用相同朝向。
- 军官的单人 Sprite 使用相同规则。
- 战场地图与格子详情预览读取同一视觉朝向。
- 不包含新增或调整步兵移动动画；该需求另行处理。

## 设计

在 `BattleScene` 内维护按单位 ID 索引的徒步单位视觉朝向。朝向使用现有六角格方向类型，并通过一个纯函数转换为 Cocos Sprite 角度；转换函数包含贴图默认朝向校准，避免各调用点重复角度计算。

移动入口在创建 `move` 动画时记录起点到终点方向。攻击入口在播放攻击表现前记录攻击者到目标方向。无精确六方向时使用现有近似方向工具；无法得到方向时保留已有视觉朝向。单位首次绘制时优先使用已记录视觉朝向，其次使用 `Unit.facing`，最后保持贴图默认角度。

视觉朝向表随任务/场景视觉状态一同清空，不写回 `Unit.facing`。这样不会改变视野、射界、后方判定、AI 决策或 PVP 权威状态。

## 绘制行为

`drawInfantry` 为普通步兵的三个 Sprite 和军官 Sprite 应用统一角度。矢量回退小人维持现有绘制方式；资源加载完成后会立即按当前视觉朝向显示。格子详情中的步兵/军官 Sprite 使用相同角度转换结果。

## 测试与验证

- 纯函数测试覆盖六个六角方向到屏幕 Sprite 角度的映射与默认朝向校准。
- BattleScene 聚焦测试确认移动和攻击入口都会更新徒步单位视觉朝向。
- 测试确认三个步兵 Sprite、军官 Sprite 和格子详情预览均应用该朝向。
- 测试确认实现不写入 `Unit.facing`，保持视觉与规则状态隔离。
- 运行相关步兵视觉测试、格式检查和差异检查。
