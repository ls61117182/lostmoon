# 重炮碉堡占格与掩护

以下规则仅适用于硬核模式和测试模式，经典模式保留原行为。日军重炮与德军重炮使用相同规则。

- 碉堡所在格保留地板和地形规则，不绘制房屋、水井、草垛等建筑装饰；击毁后仍保留这一布局。格子信息预览同步隐藏装饰。
- 存活碉堡阻挡坦克，只允许友方步兵进入；敌我判定使用战斗所属方，支持同阵营对战和跨国友军。
- 碉堡残骸仍阻挡坦克，允许双方步兵进入。其它单位残骸的占格规则不变。
- 存活的友方碉堡为同格步兵提供城市建筑掩护：机枪命中所需点数 +3，其它需命中判定的攻击沿用城市建筑 +1；与地块建筑加成取较大值。HE 沿用建筑的二元掩护值 1，不叠加。
- 击毁或敌方碉堡不提供额外掩护；底层地块本身的掩护仍正常计算。
- 无论完好还是击毁，碉堡贴图都在步兵之上。只有同格、可见的步兵在重叠像素处显示与城市建筑相同的阵营轮廓；轮廓受战争迷雾遮罩约束。
- 碉堡及残骸本身不触发步兵散开，步兵沿用紧凑队形；与坦克或其它单位同格时的原有队形规则不变。
- 碉堡本体及残骸像建筑一样保留在迷雾下，不受可见单位裁剪蒙版隐藏；没有视野时由迷雾压暗覆盖，同格步兵及其轮廓仍按视野隐藏。
- 碉堡及残骸的投影使用同样不受视野裁剪的建筑阴影层，与本体一起被迷雾压暗；炮管不重复投影。
- 玩家移动、AI 占格检查、自动撤离路径及回合结束坦克增援移动均不能绕过碉堡限制。
