# 德军坦克关卡配色

默认继续使用现有德军灰。全部 16 个德军坦克／突击炮版本新增 A 方案后期三色迷彩：暗黄、橄榄绿、红褐大斑块。

## 关卡配置

在关卡 JSON 顶层设置：

```json
"germanTankCamouflage": "late_war"
```

设置为 `"grey"` 或省略字段均使用德军灰。其他值会在加载时报告配置错误。

编辑器路径：**关卡 → 德军配色 → 德军灰 / 后期三色迷彩**。新建关卡默认灰色；导入、保存、导出及试玩保留配色设置。切回灰色时导出的 JSON 省略此字段。

**测试功能 → 坦克图片调试**：选中任意德军坦克，点击预览区左上方第二行的 **配色：德军灰 / 后期三色迷彩** 按钮切换；正常车身、炮塔和击毁预览共用此选择。切换时保留旋转角度、调试参数和击毁状态。其他车型显示“后期配色（仅德军）”，继续使用原资源；返回德军车型时保留本次调试的配色选择，重新打开调试界面则默认灰色。该按钮只改变当前调试预览，不修改关卡配置或原图。

配置按当前关卡和单位的德军阵营生效，覆盖德军玩家坦克、AI 友军、敌军、后续增援、读档恢复、击毁图、飞散炮塔及格子详情预览。车身和炮塔使用同套配色。美军、苏军、日军、步兵、卡车、牵引炮和碉堡不受影响。

欧洲战场第 1～6 关显式配置为德军灰（`grey`），第 7～13 关配置为后期三色迷彩（`late_war`）。鼠式等原型车的后期色属于统一游戏外观扩展。

## 资源和制作

- 原灰色：`assets/resources/textures/units/`，PNG 和 `.meta` 保持原文件、原 UUID、原色。
- 后期版本：`assets/resources/textures/units/late_war/`，同名独立 PNG 和新 UUID，共 54 张 PNG。
- 各层沿用原画布、透明度、裁切、炮口、舱口、支点和显示比例；击毁状态沿用原损伤结构和暗部。
- 纹样源图：`source_art/tanks/german-late-war/camouflage-master.png`，由内置 ImageGen 依据已确认 A 方案生成；完整提示词见同目录 `.prompt.txt`。按每车型的原始灰度明暗与车身坐标确定性投射，保留结构线、透明轮廓和局部焦黑；完整图沿用原有合成图的几何。
- `asset-report.json` 记录每张原 PNG、原元数据和新 PNG 的 SHA-256、透明度哈希及尺寸。
- `all-tanks-preview.png` 展示全部车型正常／击毁图及地图尺度合成；`runtime-size/` 是 `hexR=56` 的合成预览。

可重复制作和验收：

```powershell
pnpm run tank:late-war
pnpm run tank:validate
node --test tests/levelEditorTankCamouflage.test.js
```

重建只从原灰图读取，不覆盖原文件、不累计改色；已存在的后期资源保留新 UUID。资源范围从现有单位和贴图注册表推导，无需新增单位类型或修改战斗数值。
