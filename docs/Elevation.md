# 高度与格边边坡

格子用 `height` 表示绝对高度。缺省为 0，支持有限正数、负数和小数。格子中心、单位站位和六边网格不随高度偏移，始终使用 90° 垂直顶视。

```json
{"t":"f","height":1}
{"t":"f","height":-1,"cliff":"100001"}
```

`cliff` 是六位 0/1 格边配置，顺序与树篱 `h`、海堤 `sw` 相同：**E、SE、SW、W、NW、NE**。1 表示该边在存在高度差时为不可通行陡坡。可以标在高侧或低侧；任一侧标为陡坡，双向均不可跨越。两侧都配置时，1 优先。编辑器切回缓坡会同时清除邻格的相反标记。

仅当两个实际存在的相邻格高度不同时生成一条边坡，由高侧拥有，跨共享边绘制。同高格没有边坡，即使预留了 cliff 标记也不阻挡；地图缺格不视为高度 0。同高度连片地形只在外部高度变化处形成坡带。高度差增加时坡带深度温和增加并封顶，直段共享边位于坡面中央，转角小幅圆滑。

未配置 cliff 的高度变化默认是可通行缓坡；不增加移动力消耗。陡坡阻挡坦克、卡车、步兵及反坦克炮双向跨越，日本单位和忽略海堤的前进动作也不能绕过。玩家寻路、AI 规划和移动执行、卡车路线事件共用这条限制。可通行边坡仍受原有水域、桥梁进出方向、森林等规则约束。

高度参与视野与射击路径遮挡，不额外改变射程、命中率或伤害。高度与陡坡是静态关卡配置，随自定义关卡的保存、导出、导入与原关卡存档重载保留，无需新增战斗存档版本。

## 高地视野规则

- 低处单位不能直接看到高度高于自己所在格的格子；高处单位可以看到低处格，但仍受距离、朝向及沿途遮挡限制。
- 判断一条视线时，中间格只要高于目标格就会遮挡。因此既会挡住比观察者更高的格子，也会挡住高处向低处观察时高于低处目标的格子。起点自身不算中间遮挡。
- 例如 `x(1) → y(1) → z(0)`：x 能看到 y，但 y 高于 z，故 x 看不到 z。`x(1) → y(0) → z(0)` 则可以看到 z；中间格和目标同高不会因高度而遮挡。被挡住的低格后面若有更高目标，仍按该目标高度单独判断。
- 负数、小数和缺省高度 0 使用相同规则；缓坡和陡坡不改变视野判定。森林、岩地、建筑、烟雾仍使用原有遮挡规则。
- 规则覆盖步兵、车长、车内、炮手、固定炮及重炮视野。斜向射线保留原来的侧路规则：普通斜向射线在两侧都挡住时截断；关舱炮手必须保留一条完整连续侧路。每个目标都使用自己的高度判断。
- 无线电共享发送单位实际获得的视野，接收单位可以获知自身直视不到的高地。玩家视野缓存包含格子高度，修改高度后会重新计算。

## 配置入口

地图编辑器 → 选中格子 → 点击属性面板标题里的“高度 / 边坡”。可以输入高度、用 ±1 调整，以及分别切换六向“缓坡 / 陡坡”；左侧显示邻格相对本格的高度差。高度缺省为 0。清空附加会清除陡坡标记，保留作为地表属性的高度。

战场格子详情显示高度及可通行/不可通行边坡说明，地形预览裁切同一份连续坡带，包含由邻格高地拥有的坡面。

`source_art/terrain/elevation-v1/demo-package.json` 是可导入编辑器的测试关卡包，已经通过关卡加载校验，包含连续高地和左右两类边坡。

## 连续轮廓、碎石与固定光照（第五版）

第三版逐边贴图即使混合透明度，仍会在转角重启坡肩、阴影和纹理。第四版改用 `ElevationContour.ts`：

- 先连接有高差的共享边，把普通两边转角替换为相切的二次曲线；连续高地的内部边不绘制坡带。三高度交点保留物理端点，不把不同层的轮廓强行连接。
- 每个像素只计算一次到整条轮廓的距离。坡顶、坡脚、接触阴影和高低地明度层共用该距离场；主坡面以轮廓为中心，高低两侧各占一半。转角做小幅圆滑，不偏移格心、单位或通行边。
- 草坡在原地面上增加透明明暗，保留泥地、道路、草地本来的纹理；不覆盖另一张带颜色的草地贴图。岩坡使用统一世界坐标采样，跨原格边和转角不重新起纹理。草坡到岩坡的宽度、材质比例随转角连续变化。
- 第五版将平整岩石带降为疏松底层，再叠加 16 种独立透明碎石。大石块集中于坡面，小碎石在坡脚稀疏散落；世界坐标种子决定位置、尺寸、朝向，跨格边、跨绘制块、重绘和相机转向均不重新随机。
- 碎石使用中性颜色和单独的法线数据，随机转动轮廓后重新计算受光；投影始终沿屏幕右下方。不是旋转已带光照的贴图。每块石头及其阴影都在额外 22 像素的工作边缘中合成，再裁切输出，避免边缘切断石块。
- 光照与 `ObjectShadowRenderer` 一致：屏幕左上方来光、右下方投影。每个位置按曲线法线计算受光，六方向及转弯处都有不同亮暗；`cameraRotation=90` 时逆变换光线后重新生成。避免旋转复用一张固定光照资源，也避免把两个不同朝向的阴影直接叠在一起。
- 材质为 `assets/resources/textures/terrain/elevation/continuous-material.json`，版本 5，包含岩土底层和 16 张 48×48 碎石颜色/透明度与法线数据。新增碎石源图由内置 imagegen 生成，保存在 `rubble-atlas-generated-v5.png`，生产处理后的透明素材预览为 `rubble-atlas-prepared-v5.png`，完整提示词为 `rubble-prompt-v5.txt`，三者均在 `source_art/terrain/elevation-v1/`。生产脚本负责分格提取、清理透明边缘杂色、减弱大尺度烘焙明暗，并为石块建立可重新受光的面。当前运行时不加载旧的 24 张逐方向 PNG 或 `elevation-join.effect`；这些资源、脚本和旧 GPU 检查保留作第三版参考。
- 坡带以半径 48 的地图坐标生成 256×256 静态块，每块留一像素过滤边缘，显示时裁掉边缘，避免块之间重复叠加。移动、缩放和平移复用纹理；高度、陡坡配置或相机朝向变化才重新生成。格子详情裁切相同输出，节点销毁时释放自建纹理。
- 高地内部保留约 13% 明度层，负高度用暗层；该层跨坡面连续过渡。草坡适应底下的地表，岩石材质仍为温带版本，未增加雪地专用岩石。
