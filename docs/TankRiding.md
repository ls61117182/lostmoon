# 步兵自动搭乘坦克

玩家及 AI 坦克开始有效前进、后退动作时，自动搭乘同格、同阵营且同一战斗方的一支步兵小队；军官不参与。上下车不需要玩家操作，也不额外消耗骰子。移动完成后保持搭乘，直到触发下车规则。多区域地图中不播放动画的屏外移动同样支持搭乘。

- 一辆坦克搭载一支小队，支持通用、德军、苏军、日军和美军步兵。已毁、弃车或起火的坦克不能搭乘；被压制或正在操炮的步兵不能上车。转向、无效移动不会触发搭乘。
- 搭乘期间小队暂停独立移动和攻击，仍可被敌方攻击。其逻辑位置随坦克换格，存档和 PVP 快照记录载车 ID。
- 玩家坦克的搭乘者须等杂项阶段结束后才因行动结束尝试下车，移动、攻击阶段结束均保持搭乘；测试模式的合并攻击/移动阶段也一样。杂项骰子已耗尽或没有可执行动作时结束杂项阶段并尝试下车。载车所在格有其他存活步兵时无法下车，继续搭乘，但不阻止阶段推进；详情界面只显示规则和受阻原因。
- AI 坦克在本单位整套骰子行动完成后尝试下车，连续前进/后退动作之间保持搭乘；同格有其他步兵则继续搭乘。观察 PVP 对手动画时不自行修改搭乘状态，以上车方提交的快照为准。
- 主炮、HE 或机枪整次攻击结算后，无论命中与否，涉及的载车自动尝试下车。同格其他步兵的占位限制相同，双机枪及 HE 连带伤害先完整结算再检查下车。
- 机枪优先且仅攻击同格同阵营搭乘者，不把同一次攻击转移给地面步兵。搭乘者不享受步坦协同命中修正。HE 对目标格内所有普通步兵及坦克分别独立判定，不依赖主目标是否命中。
- 坦克被击毁时，仍在搭乘的小队一同阵亡，不执行下车，也不影响同格地面步兵。主炮、HE、命中时的提前击毁显示及存档/PVP 状态校验均使用此规则。
- 坦克起火、弃车或变更阵营时，步兵在载车所在格自动下车；普通下车后恢复原有同格散开阵形和后续行动。
- 桥梁格下车时，地面步兵优先站在桥面内，再寻找避开车身的位置；桥面没有足够空位时允许与坦克重叠，由坦克贴图遮挡的部分显示步兵轮廓。普通步兵步行进入或离开桥梁时，动画过程中也沿桥面收拢队形，到达陆地后恢复普通站位；不改变上下车与移动规则。
- 三个坐姿精灵是车身节点的子节点，随车身移动、转向和震动。分体炮塔绘制在乘员上方并独立旋转。
- 座位沿车身两侧按 2 + 1 分布，双人侧在每次上车时等概率选择左右。重绘、移动、旋转均不重新抽取；存档和 PVP 同步该侧。旧存档按单位 ID 稳定补齐，避免联机两端各自随机产生不同布局。调试界面每次重新搭乘也会重新抽取。
- 三个座位集中在车身后部甲板两侧，前排避开炮塔后缘；双人侧相邻而坐，尾端士兵向同伴靠拢，避免伸出车尾。
- 两侧士兵均朝车体中心内收自身显示图片高度的 5%，降低双腿伸出车体的程度；位移随精灵尺寸等比变化。

资源来源为 `source_art/infantry/american/seated-20261024-v4-palette`：沿用纯色钢盔与大色块的简化轮廓，制服和装备配色按原站姿美军校正为较深的橄榄绿与卡其棕。此前详细版和浅色简化版分别保留在 `seated-20261023-v2`、`seated-20261023-v3-small`。显示尺寸为初版的 85%，由共享比例控制。执行 `node tools/prepareTankRiderAssets.cjs` 可重新复制坐姿贴图并生成导入元数据；保留原画布和髋部锚点，以免自动裁边改变坐姿位置。缩小时使用线性采样，放大时使用最近邻采样。

座位、朝向、尺寸与髋部锚点集中在 `assets/scripts/view/TankRiderVisual.ts`，搭乘规则位于 `assets/scripts/core/TankRiding.ts`。

坐姿原画的大面积亮色在缩小后仍比原站姿明显偏亮。渲染器对三张坐姿图分别应用 RGB 增益，按各自原站姿在 24 像素内缩小后的 alpha 加权平均颜色校准；保留透明度和当前 85% 尺寸。共享的 `TANK_RIDER_COLORS` 同时用于战斗和坦克图片调试界面，颜色回归测试将三通道平均误差限制在 2/255 以内。该校正通过 Sprite.color 完成，不改变原始 PNG。

验证：`node --test tests/TankRiding.test.js` 和 `npm run typecheck`。

全阵营坐姿资源补充在 `source_art/infantry/seated-20261031-all`，使用内置 imagegen 编辑模式；完整提示词和引用图记录在 `generation-prompts.json`。德军、苏军、通用步兵沿用原站姿共用同一套贴图的关系；日军 01/03 原图相同，坐姿同样复用。所有类型的帧和校色参数由 `SEATED_INFANTRY_VISUALS` 控制，军官不在表中。坦克图片调试界面按坦克阵营选用坐姿图，搭乘按钮仅作为美术预览开关。
