# 美军步兵搭乘坦克

玩家回合中，让友军坦克与美军步兵处于同一格，点击该格打开详情，在美军步兵条目中选择“乘坐坦克”。再次打开该格，可在同一条目选择“下车”。上下车不消耗玩家坦克的骰子。

- 一辆友军坦克搭载一支三人美军小队。敌军、已毁、弃车或起火的坦克不能搭乘；被压制或正在操炮的步兵不能上车。
- 搭乘期间小队暂停独立移动和攻击，仍可被敌方攻击。其逻辑位置随坦克换格，存档和 PVP 快照记录载车 ID。
- 载车所在格有其他存活步兵时不能主动下车；详情界面显示原因并隐藏下车按钮。其他步兵离开或被消灭后可下车。
- AI 机枪在合法、可见且射程内的目标中优先攻击搭乘步兵。搭乘步兵受到机枪射击时不享受步坦协同命中修正；同格地面步兵仍沿用原协同规则。
- 坦克起火、被毁、弃车或变更阵营时，步兵在载车所在格自动下车；普通下车后恢复原有同格散开阵形和后续行动。
- 三个坐姿精灵是车身节点的子节点，随车身移动、转向和震动。分体炮塔绘制在乘员上方并独立旋转。
- 座位沿车身两侧按 2 + 1 分布，双人侧在每次上车时等概率选择左右。重绘、移动、旋转均不重新抽取；存档和 PVP 同步该侧。旧存档按单位 ID 稳定补齐，避免联机两端各自随机产生不同布局。调试界面每次重新搭乘也会重新抽取。
- 三个座位集中在车身后部甲板两侧，前排避开炮塔后缘；双人侧相邻而坐，尾端士兵向同伴靠拢，避免伸出车尾。
- 两侧士兵均朝车体中心内收自身显示图片高度的 5%，降低双腿伸出车体的程度；位移随精灵尺寸等比变化。

资源来源为 `source_art/infantry/american/seated-20261024-v4-palette`：沿用纯色钢盔与大色块的简化轮廓，制服和装备配色按原站姿美军校正为较深的橄榄绿与卡其棕。此前详细版和浅色简化版分别保留在 `seated-20261023-v2`、`seated-20261023-v3-small`。显示尺寸为初版的 85%，由共享比例控制。执行 `node tools/prepareTankRiderAssets.cjs` 可重新复制坐姿贴图并生成导入元数据；保留原画布和髋部锚点，以免自动裁边改变坐姿位置。缩小时使用线性采样，放大时使用最近邻采样。

座位、朝向、尺寸与髋部锚点集中在 `assets/scripts/view/TankRiderVisual.ts`，搭乘规则位于 `assets/scripts/core/TankRiding.ts`。

坐姿原画的大面积亮色在缩小后仍比原站姿明显偏亮。渲染器对三张坐姿图分别应用 RGB 增益，按各自原站姿在 24 像素内缩小后的 alpha 加权平均颜色校准；保留透明度和当前 85% 尺寸。共享的 `TANK_RIDER_COLORS` 同时用于战斗和坦克图片调试界面，颜色回归测试将三通道平均误差限制在 2/255 以内。该校正通过 Sprite.color 完成，不改变原始 PNG。

验证：`node --test tests/TankRiding.test.js` 和 `npm run typecheck`。
